frob: REL003 (changelog fragment required) is now a check rule: `frob check` reports every changelog.d fragment that does not validate (unknown type, bad ULID, ULID with no ticket, empty or non-ASCII body, near-miss product prefix), `frob check --ticket` also reports an open ticket with no fragment and names `frob ticket fragment`, and the changelog_fragment close guard now refuses an invalid fragment with the validation message instead of checking only that a file exists.
