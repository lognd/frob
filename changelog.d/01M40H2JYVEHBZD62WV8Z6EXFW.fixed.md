frob: Stacked directives above one item now all bind to it: a directive block (consecutive directive lines, optionally interleaved with ordinary comments, doc comments and attributes such as `#[test]`) binds every directive in it to the item below, so several `frob:tests` lines above one test no longer leave the others unbound, and a `frob:tests` directive that attaches to no item (a blank line before the item, or the end of a file) is reported as "directive is not attached to an item" instead of as an unknown symref; a blank line now ends the block (a directive followed by a blank line and an item binds the file or enclosing symbol, no longer the item two lines away).
