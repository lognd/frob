# PM036 active cycle past its end date

Each block is a small ledger. `cycle KEY start=N end=M` creates a cycle
whose first and last day are N and M days from today (UTC); `closed`
closes it.

## An active cycle that ended yesterday fires naming the cycle and the days

```text expect=fire
cycle a start=-8 end=-1
```

## An active cycle that ends today is not overdue

```text expect=clean
cycle a start=-6 end=0
```

## An active cycle still running is clean

```text expect=clean
cycle a start=-2 end=5
```

## A closed cycle past its end is clean

```text expect=clean
cycle a start=-10 end=-3 closed
```

## A planned cycle in the future is clean

```text expect=clean
cycle a start=3 end=10
```

## Each overdue cycle fires, a current one beside it does not

```text expect=fire
cycle a start=-20 end=-14
cycle b start=-13 end=-6
cycle c start=-5 end=2
```
