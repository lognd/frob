# PM011 cycle without a goal

`cycle KEY start=N end=M goal=none` creates a cycle with an empty goal.

## An open cycle with an empty goal fires

```text expect=fire
cycle a start=0 end=6 goal=none
```

## An open cycle with a goal is clean

```text expect=clean
cycle a start=0 end=6
```

## A closed cycle with an empty goal is not judged

```text expect=clean
cycle a start=-10 end=-4 goal=none closed
```
