# PM011 cycle without a goal

Each block is a small ledger. `goal=none` on a `cycle` line leaves the goal empty.

## An open cycle with no goal fires

```text expect=fire
cycle c start=-1 end=5 goal=none
```

## A planned cycle with no goal fires

```text expect=fire
cycle c start=3 end=10 goal=none
```

## A cycle with a goal is clean

```text expect=clean
cycle c start=-1 end=5
```

## A closed cycle with no goal is not judged

```text expect=clean
cycle c start=-10 end=-5 goal=none closed
```
