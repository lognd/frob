# PM033 ready queue below the order point

Each block is a small ledger. `ready_min N` sets `[pm] ready_min`; each
`task KEY` creates a doable ticket (todo, unblocked); epics are not doable.

## One doable ticket with ready_min 4 fires with the counts

```text expect=fire
ready_min 4
cycle h start=-10 end=-3 closed
task a
```

## Four doable tickets with ready_min 4 is silent

```text expect=clean
ready_min 4
task a
task b
task c
task d
```

## Tickets in progress are not ready

```text expect=fire
ready_min 2
cycle h start=-10 end=-3 closed
task a
task b state=in_progress
```

## Epics are not ready

```text expect=fire
ready_min 2
cycle h start=-10 end=-3 closed
epic e
task a
```

## A ready_min of 0 is off

```text expect=clean
ready_min 0
```

## No closed cycle yet means the rule does not apply

```text expect=clean
ready_min 4
task a
```
