# PM010 cycle over capacity

`cycle KEY start=N end=M [capacity=P] [tickets=a,b]` creates a cycle
with an explicit capacity and member tickets; `task KEY points=P`
gives a ticket story points.

## Committed points above the set capacity fire

```text expect=fire
task a points=5
task b points=5
cycle c start=0 end=6 capacity=8 tickets=a,b
```

## Committed points equal to capacity are clean

```text expect=clean
task a points=5
task b points=3
cycle c start=0 end=6 capacity=8 tickets=a,b
```

## A cycle under capacity is clean

```text expect=clean
task a points=2
cycle c start=0 end=6 capacity=8 tickets=a
```

## A closed cycle over capacity is not judged

```text expect=clean
task a points=8
task b points=8
cycle c start=-10 end=-4 capacity=8 tickets=a,b closed
```

## An empty cycle is clean

```text expect=clean
cycle c start=0 end=6 capacity=8
```
