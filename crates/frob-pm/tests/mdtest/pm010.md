# PM010 cycle over capacity

Each block is a small ledger. `cycle KEY start=N end=M [capacity=P]
[members=a,b]` creates a cycle holding the listed tickets; a task's
`points=N` sizes it. Without `capacity=` nothing is enforced until
`[pm] min_history` cycles have closed.

## A cycle committing more than its capacity fires

```text expect=fire
task a points=5
task b points=5
cycle c start=-1 end=5 capacity=8 members=a,b
```

## A cycle at its capacity is clean

```text expect=clean
task a points=5
task b points=3
cycle c start=-1 end=5 capacity=8 members=a,b
```

## Without capacity or history nothing is enforced

```text expect=clean
task a points=13
cycle c start=-1 end=5 members=a
```

## A closed cycle is not judged

```text expect=clean
task a points=13
cycle c start=-10 end=-5 capacity=3 members=a closed
```
