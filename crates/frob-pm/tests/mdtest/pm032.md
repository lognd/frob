# PM032 good-first pool low

Each block is a small ledger. `good_first_min N` sets `[tickets] good_first_min`
(default 3); `labels=good-first` marks a ticket; ready means doable (todo, unblocked).

## Two ready good-first tickets fires with the count and the minimum

```text expect=fire
task a labels=good-first
task b labels=good-first
```

## Three ready good-first tickets is silent

```text expect=clean
task a labels=good-first
task b labels=good-first
task c labels=good-first
```

## Unlabelled and in-progress tickets do not count

```text expect=fire
task a labels=good-first
task b labels=good-first
task c
task d labels=good-first state=in_progress
```

## A minimum of 0 turns the rule off

```text expect=clean
good_first_min 0
task a
```

## Unresolved when the ledger cannot be read

`unreadable` corrupts the ticket index after the ledger is built, so the rule cannot judge and reports the required Unresolved.

```text expect=unresolved
task a
unreadable
```
