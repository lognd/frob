# PM034 milestone member outside epics

Each block is a small ledger. `milestone VERSION epics=KEY,...` creates a
milestone with those member epics; `epic KEY` and `task KEY` create tickets
in order; `parent=KEY` and `labels=a,b` set their fields.

## A leaf with the release label outside the milestone's epics fires

```text expect=fire
epic in
epic out
milestone 0.532.0 epics=in
task leaf parent=out labels=release:0.532.0
```

## A leaf with the release label and no epic at all fires

```text expect=fire
epic in
milestone 0.532.0 epics=in
task leaf labels=release:0.532.0
```

## A milestone without epics claims nothing yet and fires for each label

```text expect=fire
milestone 0.532.0 epics=
task leaf labels=release:0.532.0
```

## A member epic whose child claims a different milestone fires

```text expect=fire
epic a
epic b
milestone 0.532.0 epics=a
milestone 0.533.0 epics=b
task leaf parent=a labels=release:0.533.0
```

## A leaf under a member epic is clean

```text expect=clean
epic in
milestone 0.532.0 epics=in
task leaf parent=in labels=release:0.532.0
```

## A leaf deep under a member epic is clean

```text expect=clean
epic top
epic sub parent=top
milestone 0.532.0 epics=top
task leaf parent=sub labels=release:0.532.0
```

## A member epic labelled for its own milestone is clean

```text expect=clean
epic in labels=release:0.532.0
milestone 0.532.0 epics=in
```

## A label for a version with no milestone is ignored

```text expect=clean
epic in
milestone 0.532.0 epics=in
task leaf labels=release:9.9.9
```

## A repository without milestones is not applicable and stays clean

```text expect=clean
epic a
task leaf parent=a labels=release:0.532.0
```
