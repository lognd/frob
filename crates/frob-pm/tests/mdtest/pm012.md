# PM012 cycle member fails ready_requires

`ready_requires NAME...` sets `[pm] ready_requires`. `task KEY
points=P criteria=yes` supplies points and acceptance criteria.

## A member lacking points fires

```text expect=fire
ready_requires points
task a criteria=yes
cycle c start=0 end=6 tickets=a
```

## A member lacking both criteria and points fires

```text expect=fire
ready_requires criteria points
task a
cycle c start=0 end=6 tickets=a
```

## A member meeting every predicate is clean

```text expect=clean
ready_requires criteria points
task a points=3 criteria=yes
cycle c start=0 end=6 tickets=a
```

## An empty ready_requires judges nothing

```text expect=clean
task a
cycle c start=0 end=6 tickets=a
```

## A ticket outside any cycle is not judged

```text expect=clean
ready_requires points
task a
cycle c start=0 end=6
```
