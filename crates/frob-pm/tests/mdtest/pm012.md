# PM012 cycle member that is not ready

Each block is a small ledger. `ready_requires a,b` sets `[pm] ready_requires`
(default: all five). A `task` takes `points=N`, `scope=glob`, `criteria=N`
and `parent=KEY`; a `story` carries a value statement unless `value=none`.

## A member missing points fires naming the predicate

```text expect=fire
ready_requires points
task a
cycle c start=-1 end=5 members=a
```

## A member meeting every required predicate is clean

```text expect=clean
ready_requires points,scope,criteria
task a points=3 scope=src/** criteria=1
cycle c start=-1 end=5 members=a
```

## A story without a value statement fires

```text expect=fire
ready_requires story_or_objective_qualified
story s value=none
cycle c start=-1 end=5 members=s
```

## A story with a value statement is clean

```text expect=clean
ready_requires story_or_objective_qualified
story s
cycle c start=-1 end=5 members=s
```

## A member without a parent fires under the default requirements

```text expect=fire
task a points=3 scope=src/** criteria=1
cycle c start=-1 end=5 members=a
```

## A member that is already in progress is not judged

```text expect=clean
ready_requires points
task a state=in_progress
cycle c start=-1 end=5 members=a
```

## A closed cycle is not judged

```text expect=clean
ready_requires points
task a
cycle c start=-10 end=-5 members=a closed
```
