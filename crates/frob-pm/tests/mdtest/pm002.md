# PM002 milestone epic completeness

`epic KEY state=done` closes an epic; `task KEY parent=EPIC` adds work under it.

## A milestone with no epics fires

```text expect=fire
milestone 0.532.0 epics=
```

## A member epic that is done while a child is open fires

```text expect=fire
epic in state=done
task leaf parent=in
milestone 0.532.0 epics=in
```

## A member epic that is done while a deep descendant is open fires

```text expect=fire
epic in state=done
epic sub parent=in
task leaf parent=sub
milestone 0.532.0 epics=in
```

## A member epic that is done with all work done is clean

```text expect=clean
epic in state=done
task leaf parent=in state=done
milestone 0.532.0 epics=in
```

## An open member epic with open work is clean

```text expect=clean
epic in
task leaf parent=in
milestone 0.532.0 epics=in
```

## An open task outside the member epic is clean

```text expect=clean
epic in state=done
task other
milestone 0.532.0 epics=in
```

## A repository without milestones is not applicable and stays clean

```text expect=clean
epic a
```
