# PM031 good-first ticket incomplete

Each block is a small ledger. `good_first_max N` sets the point limit (default 2);
`labels=good-first` opts a ticket in; `criteria=N` adds N Given/When/Then criteria;
`start_here=none` drops the `## Start here` section; `start_here=scaffold` leaves the
`ticket new --good-first` scaffold unfilled.

## A complete good-first ticket is silent

```text expect=clean
task a labels=good-first points=2 scope=src/a.rs criteria=1
```

## Five points fires naming the points

```text expect=fire
task a labels=good-first points=5 scope=src/a.rs criteria=1
```

## A missing Start here section fires

```text expect=fire
task a labels=good-first points=2 scope=src/a.rs criteria=1 start_here=none
```

## An unfilled Start here scaffold fires

```text expect=fire
task a labels=good-first points=2 scope=src/a.rs criteria=1 start_here=scaffold
```

## A missing scope fires

```text expect=fire
task a labels=good-first points=1 criteria=1
```

## A ticket without the label is not checked

```text expect=clean
task a points=13
```

## The limit is configurable

```text expect=clean
good_first_max 5
task a labels=good-first points=5 scope=src/a.rs criteria=1
```

## Unresolved when the ledger cannot be read

`unreadable` corrupts the ticket index after the ledger is built, so the rule cannot judge and reports the required Unresolved.

```text expect=unresolved
task a
unreadable
```
