# PM004 so_that restates i_want

`story KEY` adds a story; `as_a=`, `want=` and `so=` set its parts (underscores are spaces); `criteria=N` adds N Given/When/Then criteria.

## A so_that that adds value is clean

```text expect=clean
story a want=refuse_a_stale_base so=nothing_is_silently_reverted
```

## A so_that that repeats i_want fires

```text expect=fire
story a want=refuse_a_stale_base so=refuse_a_stale_base
```

## A story without value parts is left to PM003

```text expect=clean
story a value=none
```

## Unresolved when the ledger cannot be read

`unreadable` corrupts the ticket index after the ledger is built, so the rule cannot judge and reports the required Unresolved.

```text expect=unresolved
task a
unreadable
```
