# PM005 story criteria shape

`story KEY` adds a story; `as_a=`, `want=` and `so=` set its parts (underscores are spaces); `criteria=N` adds N Given/When/Then criteria.

## Given/When/Then criteria are clean

```text expect=clean
story a criteria=2
```

## No criteria fires

```text expect=fire
story a
```

## A plain criterion fires

```text expect=fire
story a criteria=1 criterion=plain
```

## An explicit free-form criterion is clean

```text expect=clean
story a criterion=free
```

## A task is not examined

```text expect=clean
task a
```

## Unresolved when the ledger cannot be read

`unreadable` corrupts the ticket index after the ledger is built, so the rule cannot judge and reports the required Unresolved.

```text expect=unresolved
task a
unreadable
```
