# PM007 task without parent story

`task KEY scope=GLOBS parent=KEY labels=L` adds a task.

## A user-visible task without a story fires

```text expect=fire
task a scope=crates/frob/src/**
```

## A task under a story is clean

```text expect=clean
story s
task a scope=crates/frob/src/** parent=s
```

## A task under an epic still fires

```text expect=fire
epic e
task a scope=crates/frob/src/** parent=e
```

## A no-story reason is clean

```text expect=clean
task a scope=crates/frob/src/** labels=no-story
```

## A docs-only task is clean

```text expect=clean
task a scope=docs/**
```

## A task without scope is clean

```text expect=clean
task a
```

## Unresolved when the ledger cannot be read

`unreadable` corrupts the ticket index after the ledger is built, so the rule cannot judge and reports the required Unresolved.

```text expect=unresolved
task a
unreadable
```
