# PM013 WIP limit exceeded

Each block is a small ledger. `limit N` sets `[pm.wip] in_progress`;
`task KEY` creates a ticket and `task KEY state=in_progress` moves it
into progress.

## Three in progress with limit 2 fires naming the holders

```text expect=fire
limit 2
task a state=in_progress
task b state=in_progress
task c state=in_progress
```

## Two in progress with limit 2 is clean

```text expect=clean
limit 2
task a state=in_progress
task b state=in_progress
```

## Tickets not in progress do not count

```text expect=clean
limit 1
task a state=in_progress
task b
task c
```

## A limit of 0 is off

```text expect=clean
limit 0
task a state=in_progress
task b state=in_progress
```
