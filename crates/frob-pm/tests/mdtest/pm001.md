# PM001 milestone without goal

`milestone VERSION epics=KEY,... [goal=none] [criteria=none]` creates a
milestone; by default it has a goal and one exit criterion. A milestone
with no target date is `unscheduled`, which is allowed.

## A milestone with no goal fires

```text expect=fire
epic in
milestone 0.532.0 epics=in goal=none
```

## A milestone with no exit criteria fires

```text expect=fire
epic in
milestone 0.532.0 epics=in criteria=none
```

## A milestone with neither goal nor criteria fires once

```text expect=fire
epic in
milestone 0.532.0 epics=in goal=none criteria=none
```

## An unscheduled milestone with a goal and criteria is clean

```text expect=clean
epic in
milestone 0.532.0 epics=in
```

## A repository without milestones is not applicable and stays clean

```text expect=clean
epic a
```
