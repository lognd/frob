# PM009 unsized ticket in ready

Each block is a small ledger; a ready ticket is a non-epic in `todo`.

## A ready ticket without points fires

```text expect=fire
task a
```

## A sized ready ticket is silent

```text expect=clean
task a points=2
```

## An unsized ticket in progress is not ready

```text expect=clean
task a state=in_progress
```

## An unsized epic is not ready

```text expect=clean
epic e
```

## Unresolved when the ledger cannot be read

`unreadable` corrupts the ticket index after the ledger is built, so the rule cannot judge and reports the required Unresolved.

```text expect=unresolved
task a
unreadable
```
