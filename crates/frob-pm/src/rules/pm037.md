# PM037 obligation-unplanned

A design obligation has no live implementing ticket.

## What it does

Fires once per grimble obligation anchor (unrealized goal, unimplemented step,
unbound impl) that no live ticket names in `implements`. It stays silent until
some ticket uses `implements`, so repos that have not adopted the planning
join see nothing.

## Why it matters

An obligation nobody is assigned to is planned work the ledger cannot see.

## Remedy

Run `frob plan --from-design --apply`, or create the ticket with
`--implements design:<anchor>`.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
