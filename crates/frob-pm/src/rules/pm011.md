# PM011 cycle-without-goal

A planned or active cycle has no goal.

## What it does

Fires once per planned or active cycle whose goal is empty or only whitespace. `cycle new` requires a goal, so this catches cycles edited or merged in without one.

## Why it matters

A cycle is a commitment to an outcome; without a stated goal the team cannot tell at review whether the cycle succeeded.

## Remedy

State the outcome the cycle commits to: recreate it with `frob cycle new --goal TEXT`.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
