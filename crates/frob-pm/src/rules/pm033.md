# PM033 ready-queue-low

The ready queue holds fewer doable tickets than `[pm] ready_min`.

## What it does

Advisory only: it never fails the gate. A `ready_min` of 0 turns the rule
off.

## Why it matters

An empty ready queue stalls the team; the advisory prompts replenishment before work runs out.

## Remedy

Plan the next cycle (run `frob cycle plan`) or triage the backlog so more tickets become
doable, or lower `[pm] ready_min` in `frob.toml`.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
