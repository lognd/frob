# PM039 done-untouched

A ticket closed done without touching anything bound to the design it implements.

## What it does

For each ticket closed `done` with `implements design:<anchor>` links, compares
the code identities its landed diff touched with the identities bound to the
implemented entities. It fires when none overlap. It stays silent when the
entities have no bound identity (nothing to compare) or when the host cannot
read bindings or landed diffs.

## Why it matters

A ticket that says it implemented a design entity but changed none of the code
bound to it probably closed the wrong work, or the binding points elsewhere.

## Remedy

Bind the code the ticket changed with `grimble:binds`, or correct the
ticket's `implements` link to the entity it really changed.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
