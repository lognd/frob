# DSL001 unknown-directive-verb

A directive names a verb its namespace does not declare.

## What it does

The namespace is honoured but the verb is not registered; the message carries a did-you-mean suggestion when a declared verb is close.

## Why it matters

An unknown verb binds nothing, so the author's intent is lost without a diagnostic.

## Remedy

Fix the spelling or remove the directive.

## Examples

### Fires case 1

```rust expect=fire
/* frob:tickt 01J9QKX3M8Z4T7N2V5B6C0D1E2 */ // error: DSL001
fn a() {}
```

### Clean case 1

```rust expect=clean
/* frob:ticket 01J9QKX3M8Z4T7N2V5B6C0D1E2 */
fn a() {}
```
