# DSL002 abbreviated-ticket-id

A directive carries an abbreviated ticket id instead of a full 26-char ULID.

## What it does

Only full ULIDs persist in tracked text (D24). Handles (`~3M8Z4T7`, bare 7-char forms) and v1 `T-0042` forms are flagged.

## Why it matters

Handles are ambiguous across time and clones; the full id is the only stable reference.

## Remedy

Replace the handle with the full id that `frob ticket show <handle>` prints.

## Examples

### Fires case 1

```rust expect=fire
/* frob:ticket T-0042 */ // error: DSL002
fn a() {}
```

### Clean case 1

```rust expect=clean
/* frob:ticket 01J9QKX3M8Z4T7N2V5B6C0D1E2 */
fn a() {}
```
