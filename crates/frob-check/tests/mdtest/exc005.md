# EXC005 accept not attested

A `frob:accept` whose bound symbol has no matching lock entry fires.

## An unattested accept fires

```text expect=fire
=== src/lib.rs
//! Library.

/* frob:accept COV001 because="temporary hack for now" */
/// Documented.
pub fn accepted() {}
```

## An acked accept is clean

```text expect=clean
=== src/lib.rs
//! Library.

/* frob:accept COV001 because="temporary hack for now" */
/// Documented.
pub fn accepted() {}
=== git
=== ack src/lib.rs::accepted
```
