# GRL016 repository rule file whose examples fail

A `.grl` file in the repository has every embedded example run; an example
that does not match, or a file that does not compile, fires.

## A fire example whose expectation is missing fires

```text expect=fire file=rules/nope.grl
rule NOPE001 "danger-call" {
  lang rust
  severity error
  find c: call where c.callee == "danger"
  report c "danger on line {c.line}"
  example fire rust """
    fn b() {
        danger();
    }
  """
  example clean rust """
    fn b() {
        safe();
    }
  """
  explain """
    Danger bites.

    ## Remedy
    Call something safe.
  """
}
```

## A file that does not compile fires

```text expect=fire file=rules/broken.grl
rule {
```

## A rule whose examples all match is clean

rule NOPE001 "danger-call" {
