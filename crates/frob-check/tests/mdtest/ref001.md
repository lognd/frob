# REF001 dangling ticket references

A repository with a ledger of one open and one done ticket; `{{OPEN}}` and `{{DONE}}` expand to their ids.

## Fires on an unknown ticket reference

```rust expect=fire
/* frob:ticket T-9999 */ // error: REF001
fn a() {}
```

## Clean for open and done tickets

```rust expect=clean
/* frob:ticket {{OPEN}} */
fn a() {}
/* frob:ticket {{DONE}} */
fn b() {}
```

## Unresolved when the ledger holds no ticket to resolve against

The ledger exists but is empty (`{{VACUOUS}}`), so REF001 examined zero subjects and says so
instead of passing.

```rust expect=unresolved reason=vacuous
/* frob:ticket T-9999 */ // {{VACUOUS}}
fn a() {}
```
