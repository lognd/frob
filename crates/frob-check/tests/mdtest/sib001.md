# SIB001 sibling unavailable

The block is the mode file of a fake `grimble` sibling in a repository that
configures it.

## A sibling that exits nonzero fires

```text expect=fire file=.fake-sibling
exit3
```

## A sibling that answers is clean

```text expect=clean file=.fake-sibling
valid -
```

## A sibling that exits nonzero leaves the sibling's rules unresolved

```text expect=unresolved file=.fake-sibling
exit3
```
