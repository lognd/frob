# MDL022 mdl-nonexhaustive

A `=>` match leaves an outcome variant of its element without an arm.

## What it does

Every outcome of the matched element, `ok` included, must be covered by an arm.

## Why it matters

An uncovered variant is a path the plan does not say what to do with.

## Remedy

Add an arm for each missing variant, or a `_` arm if a catch-all is intended.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky => {
      bad -> end err(bad);
    }
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky => {
      ok -> end ok;
      bad -> end err(bad);
    }
  }
}
```
