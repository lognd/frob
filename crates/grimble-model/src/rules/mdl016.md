# MDL016 mdl-unknown-atom

A capability atom is in no registry and no enabled pack.

## What it does

Atoms resolve against the registry (and, qualified, against the named pack).

## Why it matters

An atom outside every registry cannot be checked against anything, so a `may` clause that names it grants a capability nobody can verify.

## Remedy

Fix the atom name, or enable the pack that declares it.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb config="pack=grimble/threat,1.2.0,blake3:aa,injection.sql"
grimble = "2";
module m;
pack threat {
  ref "grimble/threat";
  version "1.2.0";
  digest "blake3:aa";
}
node n : trusted {
  may threat::nope at "x/**";
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb config="pack=grimble/threat,1.2.0,blake3:aa,injection.sql"
grimble = "2";
module m;
pack threat {
  ref "grimble/threat";
  version "1.2.0";
  digest "blake3:aa";
}
node n : trusted {
  may threat::injection.sql at "x/**";
}
```
