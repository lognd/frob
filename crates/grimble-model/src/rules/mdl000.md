# MDL000 mdl-syntax

Lexical or syntax error, bad encoding, or a forbidden construct.

## What it does

Covers invalid UTF-8, a byte-order mark, NUL, a bare CR, an unknown token, a keyword used as a name, a hand-written `baseline`, a bare `because "..."` and a slug rule alias. A syntax error becomes a `hole` and the rest of the file is still read.

## Why it matters

A file that does not parse cannot be judged. Grimble keeps going after a syntax error by turning the damaged span into a hole, but every rule that reads that span is then unsure.

## Remedy

Fix the token or construct the message names. Run `grimble fmt` on the file once it parses.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
@@@
node a : trusted {
  owns "src/**";
}
```

### Fires case 2

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  baseline SYS004;
}
```

### Clean case 3

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
}
```
