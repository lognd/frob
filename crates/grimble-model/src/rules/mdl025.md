# MDL025 mdl-unreachable-arm

A match or handle arm matches no outcome of its domain, or ties with another arm of equal specificity.

## What it does

Arms are ranked: `step.variant` beats a bare variant beats `_`. An arm that is never the best for any pair is dead.

## Why it matters

A dead arm is dead code that looks like handling.

## Remedy

Remove the arm or fix its variant name.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky => {
      ok -> end ok;
      bad -> end err(bad);
      nope -> end ok;
    }
  }
}
```
