# MDL029 mdl-scenario-start

A scenario starts with a system step instead of an actor step.

## What it does

The first element of the main chain must be an actor step (or an include that starts with one).

## Why it matters

Scenarios describe what an actor does; a system-first scenario has no trigger.

## Remedy

Begin the chain with the actor step that triggers the system.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    system.work -> end ok;
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.work -> end ok;
  }
}
```
