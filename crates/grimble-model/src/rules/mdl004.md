# MDL004 mdl-unknown-pack

A pack is not enabled, not under `packs/`, or its version or digest differs from the pin.

## What it does

Pins are exact so a model and a pack move together.

## Why it matters

A pack changes what atoms and rules mean. A model written against one pack version and checked against another can pass or fail for reasons that are not in the model.

## Remedy

Update the pin in the pack declaration, or install the pinned version of the pack.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb config="pack=grimble/threat,1.1.0,blake3:aa,injection.sql"
grimble = "2";
module m;
pack threat {
  ref "grimble/threat";
  version "1.2.0";
  digest "blake3:aa";
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb config="pack=grimble/threat,1.2.0,blake3:aa,injection.sql"
grimble = "2";
module m;
pack threat {
  ref "grimble/threat";
  version "1.2.0";
  digest "blake3:aa";
}
```
