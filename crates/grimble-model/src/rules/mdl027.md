# MDL027 mdl-retry

A `retry` is misplaced, has no valid `max`, or does not target a step on its path.

## What it does

`retry` may only end an arm chain, needs `max N` with N at least 1, and must name a step on the path to the arm.

## Why it matters

An unbounded or dangling retry is a loop the plan cannot bound.

## Remedy

Add `max N`, retarget the step, or move the retry to an arm tail.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky => {
      ok -> end ok;
      bad -> retry u.go;
    }
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky => {
      ok -> end ok;
      bad -> retry u.go max 2;
    }
  }
}
```
