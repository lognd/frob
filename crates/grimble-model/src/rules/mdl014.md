# MDL014 mdl-vmodel

A V-model construction error.

## What it does

Wrong endpoint kinds, unpaired levels on `verifies`, a missing `ref` or `runnable`, a duplicate link, or `supersedes` without `because`.

## Why it matters

The V-model links requirements to the tests that verify them. A link with the wrong endpoints, or a test with nothing to run, verifies nothing while looking as if it does.

## Remedy

Give a test a `runnable`, an artifact a `ref`, and pair the levels on every `verifies`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
vmodel t_missing {
  kind test;
  level customer_test;
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
vmodel req {
  kind artifact;
  level requirements;
  ref "docs/design/a.md#req";
}
vmodel t_ok {
  kind test;
  level acceptance;
  runnable "t.rs::ok";
  verifies req;
}
```
