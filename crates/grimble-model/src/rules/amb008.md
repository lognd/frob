# AMB008 amb-unverified-policy

A system ambient policy has no `verified_by` test.

## What it does

A system `ambient POLICY;` written without a `{ verified_by ... }` body is flagged once, at the policy. A system with no policy at all is AMB001, and scenario overrides are not checked here.

## Why it matters

An ambient policy is a promise about behavior under faults; with no test bound to it nothing shows that the promise holds.

## Remedy

Give the policy a body naming the test: `ambient retry max 2 { verified_by "tests/ambient.py"; }`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  ambient escalate;
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  ambient escalate { verified_by "tests/ambient.py"; }
}
```
