# MDL012 mdl-deprecated-name

A reference uses a `renamed_from` name.

## What it does

Edit the reference to the new name. The clause itself is reported once no lock entry needs it (that half needs the lock and is evaluated by the binary).

## Why it matters

A `renamed_from` name keeps old locks and references alive across a rename. A reference that still uses it will break the day the clause goes.

## Remedy

Edit the reference to the new name.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node new_name : trusted {
  renamed_from old_name;
  alias legacy;
}
flow f : old_name -> legacy {
  label Public;
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node new_name : trusted {
  renamed_from old_name;
  alias legacy;
}
flow f : new_name -> legacy {
  label Public;
}
```
