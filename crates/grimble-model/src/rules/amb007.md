# AMB007 amb-domain-panic

A mapped domain error is converted to a panic by the bound unit.

## What it does

A waypoint outcome-map source that names a panic-converting call (`unwrap`, `expect` or `panic`) instead of a domain error is flagged at the source. Detecting the conversion in the bound code (a clippy-style query) needs a language adapter and is not done here.

## Why it matters

A panic turns a modeled domain outcome into a defect, so the declared variant is never reached.

## Remedy

Handle the error and return the mapped variant instead of unwrapping.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  ambient escalate { verified_by "tests/a.py"; }
  actor u : human;
  step u.go : { ok, bad };

  scenario t {
    u.go => {
      ok => end ok;
      bad => end err(bad);
    }
  }

  impl u.go for t {
    chain {
      call c = "a.py::c" {
        unwrap => bad;
        verified_by "tests/a.py";
      }
    }
  }
}
```
