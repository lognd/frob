# MDL034 mdl-exclusive

A `one_of exclusive` group whose alternatives overlap.

## What it does

Only one overlap shape is decided and checked: the same alternative written twice in one `one_of exclusive` group. The grmb-spec (15.5, 16.1) does not define any wider notion of overlap, so none is reported. A `one_of` without `exclusive` is not read.

## Why it matters

An exclusive group promises that exactly one alternative holds, which a repeated alternative cannot honour.

## Remedy

Remove the repeated alternative, or drop `exclusive`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;

  goal u { start; }
  goal u.start { one_of exclusive { card; card; } }

  scenario t realizes u.start.card {
    u.go -> end ok;
  }
}
```
