# MDL019 mdl-orphan-file

A .grmb file in the walk is reachable from no model root.

## What it does

Only files reachable from a root listed in `[grimble] models` through `include` are loaded. Include the file from a root, list it as a root, or exclude it with `[check] exclude`; rustc ignores unreachable files silently, grimble does not.

## Why it matters

A model file that no root reaches is never read, so the entities in it do not exist as far as any check can tell.

## Remedy

Include the file from a root, list it as a root, or exclude it with `[check] exclude`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb config="orphan"
grimble = "2";
part of m;
node a : trusted {
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb config="included"
grimble = "2";
part of m;
node a : trusted {
}
```
