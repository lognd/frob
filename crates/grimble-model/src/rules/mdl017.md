# MDL017 mdl-duplicate-clause

A list clause repeated with identical content.

## What it does

The formatter removes the duplicate.

## Why it matters

A repeated list clause says nothing new and hides which of the copies is the one a reader should edit.

## Remedy

Delete the duplicate; `grimble fmt` does it for you.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node b : trusted {
  owns "z" | "a";
  kind component;
  owns "a" | "z";
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node b : trusted {
  owns "z" | "a";
  kind component;
}
```
