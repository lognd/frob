# MDL028 mdl-wildcard-arm

A `_` arm hides outcome variants added later.

## What it does

A `_` arm matches every variant not matched by a more specific arm.

## Why it matters

A catch-all silently absorbs variants added later, defeating MDL022.

## Severity

grmb-planning 7.1 asks for a warning; gob-rules currently has only `Error` and `Unresolved`, so this rule reports as an error until a warn severity exists.

## Remedy

Name each variant explicitly.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky => {
      ok -> end ok;
      _ -> end ok;
    }
  }
}
```
