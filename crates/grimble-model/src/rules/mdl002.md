# MDL002 mdl-unresolved-include

An include names a missing file, matches nothing, escapes the repository or is not readable.

## What it does

Includes are structural: a file that is missing is an error, unlike a selector that matches nothing.

## Why it matters

A model that includes a file it cannot read is incomplete, and every entity in the missing file is a hidden gap in what the checks see.

## Remedy

Create the file, correct the path, or remove the include.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
include "gone.grmb";
```

### Clean case 2

```grmb expect=clean file=design/model.grmb config="shared"
grimble = "2";
module m;
include "shared.grmb";
```
