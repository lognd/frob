# MDL021 mdl-no-root

No model root is declared, or a declared root is not a .grmb file of the walk.

## What it does

Declare the entry file with `[grimble] models = ["design/model.grmb"]` in grimble.toml (`grimble init` writes it). Reported as a required Unresolved finding, so the gate fails until a root is declared.

## Why it matters

Without a root there is no model to load, and a gate that passes on no model passes on nothing.

## Remedy

Declare the entry file with `[grimble] models = ["design/model.grmb"]` in `grimble.toml`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb config="no-roots"
grimble = "2";
module m;
node a : trusted {
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
}
```
