# MDL024 mdl-fallible-sequence

A `->` hop follows an element that can fail, or a `-!>` hop follows one that cannot succeed.

## What it does

`->` requires an element whose only outcome is `ok`; `-!>` requires an element with an `ok` outcome.

## Why it matters

The hop operator states how failure is treated; a wrong one hides or invents a path.

## Remedy

Use `-!>` to collect failures, or `=>` to branch on them.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t fails with { bad } {
    u.go -> system.flaky -> end ok;
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t fails with { bad } {
    u.go -> system.flaky -!> end ok;
  }
}
```
