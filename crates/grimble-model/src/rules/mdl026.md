# MDL026 mdl-unterminated

A scenario chain does not end, a scenario has no main chain, or the include graph has a cycle.

## What it does

Every chain must end with `end ok`, `end err(..)`, `retry` or a `=>` match.

## Why it matters

An unterminated chain leaves the scenario's outcome undefined.

## Remedy

Finish the chain with `-> end ok;` or an explicit error end.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.work;
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.work -> end ok;
  }
}
```
