# MDL005 mdl-selector-no-file

A selector's path matches no file in the walk.

## What it does

A warning by design: a model may describe code that does not exist yet. It suppresses SYS004 for the same selector.

## Why it matters

A selector that matches no file usually means a typo or a deleted directory, so the node it describes owns nothing. It is a warning because a model may legitimately lead the code.

## Remedy

Correct the path, or leave the warning in place until the code lands.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb config="walk"
grimble = "2";
module m;
node a : trusted {
  owns "crates/ghost/**";
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb config="walk"
grimble = "2";
module m;
node a : trusted {
  owns "crates/a/**";
}
```
