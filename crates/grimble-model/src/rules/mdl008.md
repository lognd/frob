# MDL008 mdl-field

A required field is missing, a scalar clause appears twice, or an `extend` sets a scalar.

## What it does

Required: node trust, flow label, contract shape, claim what, vmodel kind and level, pack ref and version.

A `may` grant states why it is held: `because="..."` or `ticket="..."` (a blank string does not count). A grant without either is reported as an error so the reason is asked for, and the grant ratchet in `grimble status` lists it.

A `may` argument has the type its atom takes: a path pattern for `fs`, `fs.read` and `fs.write` (no `..` segment, no `[` or `{`), a `host[:port]` pattern for `net`, `net.connect` and `net.listen` (lowercase, no scheme, an optional `*.` prefix), an environment variable name for `process.env`, a binary name for `process.spawn`. A pack atom takes the kind its `[[atom]]` row declares with `args` (`path`, `host`, `name` or `string`); a pack atom that declares none takes no arguments. An argument of the wrong type, an empty one, or one on an atom that takes none is an error, because CAP001 enforces it at each call site.

A node's `provides C via S` needs `S` to be a symbol the node owns: every path the `via` selector names must fall under one of the node's `owns` selectors. An unowned or foreign-owned `S` is an error. A node whose `owns` is not a plain glob (or union of globs) is not checked.

## Why it matters

A required field that is missing leaves an entity half described. The checks that read the field cannot tell "not set" from "set to the default".

## Remedy

Add the missing clause, or remove the repeated one. Change a scalar in the original declaration, not in an `extend`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a {
  owns "src/**";
}
```

### Fires case 2

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  may fs.read at "src/**";
}
```

### Clean case 3

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  may fs.read at "src/**" because="reads fixtures";
  may fs.write at "src/**" ticket="T-0042";
}
```

### Clean case 4

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
}
```

### Fires case 5

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  may net.connect("https://api.example.com/v1") because="calls the api";
}
```

### Fires case 6

A `provides C via S` names a boundary the declaring node must own.

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/a/**";
  provides fs.write via "src/b/store.rs::put" because="not a's symbol";
}
node b : trusted {
  owns "src/b/**";
}
```

### Clean case 7

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/a/**";
  provides fs.write via "src/a/store.rs::put" because="the one writer";
}
```
