# MDL008 mdl-field

A required field is missing, a scalar clause appears twice, or an `extend` sets a scalar.

## What it does

Required: node trust, flow label, contract shape, claim what, vmodel kind and level, pack ref and version.

A `may` grant states why it is held: `because="..."` or `ticket="..."` (a blank string does not count). A grant without either is reported as a warning so the reason is asked for, and the grant ratchet in `grimble status` lists it.

A `may` argument has the type its atom takes: a path pattern for `fs`, `fs.read` and `fs.write` (no `..` segment, no `[` or `{`), a `host[:port]` pattern for `net`, `net.connect` and `net.listen` (lowercase, no scheme, an optional `*.` prefix), an environment variable name for `process.env`, a binary name for `process.spawn`. An argument of the wrong type, an empty one, or one on an atom that takes none is an error, because CAP001 enforces it at each call site.

## Why it matters

A required field that is missing leaves an entity half described. The checks that read the field cannot tell "not set" from "set to the default".

## Remedy

Add the missing clause, or remove the repeated one. Change a scalar in the original declaration, not in an `extend`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a {
  owns "src/**";
}
```

### Fires case 2

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  may fs.read at "src/**";
}
```

### Clean case 3

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  may fs.read at "src/**" because="reads fixtures";
  may fs.write at "src/**" ticket="T-0042";
}
```

### Clean case 4

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
}
```

### Fires case 5

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns "src/**";
  may net.connect("https://api.example.com/v1") because="calls the api";
}
```
