# AMB001 amb-policy-missing

A system declares no ambient policy.

## What it does

A `system` whose body has no `ambient POLICY` clause is flagged once, at the system name.

## Why it matters

Ambient faults (exhaustion, defects, interruption, kills) are always handled; with no declared policy the model is silent about what happens to them.

## Remedy

Declare one policy, usually the safe default: `ambient terminate;`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  ambient terminate { verified_by "tests/a.py"; }
}
```
