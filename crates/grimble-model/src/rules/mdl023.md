# MDL023 mdl-unhandled

An error variant is collected by `-!>` but neither handled nor declared in `fails with`.

## What it does

A `-!>` hop collects the non-ok variants of its element; each must be handled by a `handle` arm or propagated through `fails with`.

## Why it matters

An unhandled variant is an error path that silently disappears from the plan.

## Remedy

Add a `handle` arm for the variant, or list it in `fails with { .. }`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t {
    u.go -> system.flaky -!> end ok;
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.work;
  step system.flaky -> { ok, bad };

  scenario t fails with { bad } {
    u.go -> system.flaky -!> end ok;
  }
}
```
