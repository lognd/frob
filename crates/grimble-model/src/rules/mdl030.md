# MDL030 mdl-requires-cycle

Goal variants form a `requires` cycle.

## What it does

`requires` edges between goal variants must form a DAG.

## Why it matters

A cycle means no goal in it can ever be first.

## Remedy

Break the cycle by removing one `requires`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  goal u as action {
    a requires b;
    b requires a;
  }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  goal u as action {
    a requires b;
    b;
  }
}
```
