# MDL010 mdl-selector-empty-by-construction

A selector that cannot match anything whatever the repository holds.

## What it does

For example `lang(rust) & lang(python)` or `a & !a`.

## Why it matters

A selector that can never match is dead text. It reads as if it constrained something, and it does not.

## Remedy

Remove the contradiction, or split the selector into the two intended ones.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns lang(rust) & lang(python);
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns lang(rust);
}
```
