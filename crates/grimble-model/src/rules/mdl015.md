# MDL015 mdl-shadow

A reference resolved to a nearer entity that shadows an outer one of the same name.

## What it does

Shadowing is legal and reported; anchor the reference with a leading `::` to name the outer one.

## Why it matters

Shadowing is legal, but a reader of the reference may take it for the outer entity. The advisory marks the places where the nearer name wins.

## Remedy

Rename the inner entity, or anchor the reference with a leading `::` to name the outer one.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb

}

  }

    label Public;
  }
}
```
