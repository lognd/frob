# MDL001 mdl-duplicate-entity

Two declarations of one full name.

## What it does

Entities, aliases and `renamed_from` names share one namespace per model; the first in (path, byte) order is kept. Use `extend` to add to an existing entity.

## Why it matters

Two entities with one name make every reference to that name ambiguous. The model keeps the first and drops the rest, so the dropped declaration silently stops counting.

## Remedy

Rename one of the entities, or move the second declaration into an `extend` of the first.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node dup : trusted {
}
node dup : trusted {
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node one : trusted {
}
node two : trusted {
}
```
