# SYS016 sys-flow-absent

A declared flow is exercised by no step use or waypoint hop.

## What it does

A declared `flow` that no consecutive step-use pair exercises is reported. It is Unresolved while a step use or waypoint hop with an unknown node could exercise it.

## Why it matters

A flow no behaviour uses is dead structure, or the scenario that needs it is missing.

## Remedy

Remove the flow, or add the step use that moves data along it.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node n1 : trusted { attr stateful; }
node n2 : trusted { kind store; }

flow f : n2 -> n1 { label Internal; }
system s {
  actor a : human;
  actor b : human;
  step a.one;
  step b.two;
  scenario t {
    a.one -> b.two => { ok -> end ok; }
  }
  impl a.one for t { in node n1; }
  impl b.two for t { in node n1; }
}
```
