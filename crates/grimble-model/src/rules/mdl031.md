# MDL031 mdl-planning

A planning item is malformed: outside a system, a reserved name, an unknown kind, or an inconsistent reference.

## What it does

Planning items must sit inside a `system`, avoid planning words as names, use known actor and realization kinds, and keep `requires` and `impl` references consistent.

## Why it matters

These are structural mistakes that make the plan unreadable by tools.

## Remedy

Fix the named item.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
actor lone : human;
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  actor lone : human;
}
```
