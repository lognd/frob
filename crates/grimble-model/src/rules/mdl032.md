# MDL032 mdl-unknown-arm

An `unknown` arm that is the only arm, or a known variant has no arm.

## What it does

In a `=>` match, `unknown` is legal only when every known variant has its own arm. The rule reports an `unknown` arm that stands alone, and an `unknown` arm in a match where a known variant is left without an arm (the message names the missing variants). A match with an `unknown` arm never reports MDL025 for that arm.

## Why it matters

The `unknown` arm exists to receive variants added later or owned outside the model; used as a shortcut for the known variants it hides them like `_` does (grmb-spec 15.4, D140).

## Remedy

Add an arm for each known variant, or drop the `unknown` arm.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  actor u : human;
  step u.go;
  step system.flaky : { ok, bad };

  scenario t fails with { bad } {
    u.go -> system.flaky => {
      unknown => end err(bad);
    }
  }
}
```
