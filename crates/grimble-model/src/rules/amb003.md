# AMB003 amb-unbounded

A `retry` or `restart` ambient policy has no `max` or no `else` tail.

## What it does

A `retry` or `restart` policy, on a system or a scenario override, or in an `else` fallback, that lacks `max N` or lacks an `else POLICY` tail is flagged at the action word. The finding names what is missing.

## Why it matters

An unbounded repeat turns a persistent fault into a restart storm or crash loop; the bound and the escalation tail make the repeat terminate.

## Remedy

Write the full tail: `ambient retry max 3 else escalate;`.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;

system s {
  ambient retry { verified_by "tests/a.py"; }
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;

system s {
  ambient retry max 3 else escalate { verified_by "tests/a.py"; }
}
```
