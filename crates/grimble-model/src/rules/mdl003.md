# MDL003 mdl-include-cycle

The include graph has a cycle.

## What it does

The offending include is skipped so the rest of the model still loads. A diamond is not a cycle.

## Why it matters

An include cycle has no load order. Grimble breaks it by skipping one include, so which file wins would otherwise depend on traversal order.

## Remedy

Move the shared declarations into a file both sides include, and remove the back edge.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb config="cycle"
grimble = "2";
module m;
include "b.grmb";
```

### Clean case 2

```grmb expect=clean file=design/model.grmb config="shared"
grimble = "2";
module m;
include "shared.grmb";
```
