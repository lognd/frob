# MDL009 mdl-type

An ill-typed value.

## What it does

A unit outside the closed table, a quantity of the wrong dimension, a path with `..` or an empty path, a boundary pair on the wrong lattice, an unknown lattice element or a malformed date.

## Why it matters

A value of the wrong type does not mean what the author intended: `30 parsec` is not a duration, and a boundary pair on the wrong lattice is not a flow of information.

## Remedy

Use a unit from the closed table, a path without `..`, and a valid date.

## Examples

### Fires case 1

```grmb expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  attr t1 = 30 parsec;
}
```

### Clean case 2

```grmb expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  attr t1 = 30 s;
}
```
