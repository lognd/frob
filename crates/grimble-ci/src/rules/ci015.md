# CI015 action-currency

An external action from an archived repository or on an end-of-life Node runtime.

## What it does

Fires for a step that uses an action from a small offline table: repositories that are archived, and majors of the common `actions/*` actions that run on Node 16 or older. A SHA, branch or expression ref has no known major and is not judged, and an unknown action is not judged. Staying behind the latest release is covered by Dependabot under CI012, and an online check is `frob audit --online`.

## Why it matters

An archived action gets no fixes, and an action on an end-of-life Node runtime stops working when GitHub removes that runtime.

## Remedy

Replace the archived action, or move to a major that runs on a supported Node runtime.

## Examples

### Fires case 1

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
```

### Fires case 2

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/create-release@aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
```

### Clean case 3

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```

### Clean case 4

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
```
