# CI006 no-prt-head-checkout

A privileged trigger that checks out the pull request head.

## What it does

Fires when a `pull_request_target` or `workflow_run` workflow has an `actions/checkout` step whose `ref` or `repository` names the pull request head (`github.event.pull_request.head.*`, `github.head_ref`, `github.event.workflow_run.head_*`, `refs/pull/...`, the merge commit).

## Why it matters

These triggers run in the base repository with a privileged token. Checking out the head and building it hands that token to the author of the pull request.

## Remedy

Build untrusted code in a `pull_request` workflow with read-only permissions and pass results to the privileged workflow as an artifact.

## Examples

### Fires case 1

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.pull_request.head.sha }}
```

### Fires case 2

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: workflow_run
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.workflow_run.head_sha }}
```

### Fires case 3

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          repository: ${{ github.event.pull_request.head.repo.full_name }}
```

### Clean case 4

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```

### Clean case 5

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.pull_request.head.sha }}
```
