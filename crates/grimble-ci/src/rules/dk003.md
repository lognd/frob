# DK003 dk-floating-tag

A base image with no tag or the latest tag.

## What it does

Fires for an external `FROM` that has no tag and no digest, or the `latest` tag. Variable images (`$BASE`), `scratch` and earlier stage names are skipped.

## Why it matters

`latest` changes under you, so two builds of one commit can differ.

## Remedy

Pin a version tag, or better a digest.

## Examples

### Fires case 1

```dockerfile expect=fire file=Dockerfile
FROM debian
USER app
```

### Fires case 2

```dockerfile expect=fire file=Dockerfile
FROM debian:latest
USER app
```

### Clean case 3

```dockerfile expect=clean file=Dockerfile
FROM debian:12
USER app
```

### Clean case 4

```dockerfile expect=clean file=Dockerfile
FROM debian:12 AS build
FROM build
USER app
```

### Clean case 5

```dockerfile expect=clean file=Dockerfile
FROM scratch
COPY app /app
```
