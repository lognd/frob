# CI016 trust-from-protected-ref

A privileged workflow that runs frob, grimble or crunk with trust not read from a protected ref.

## What it does

Fires for a `frob`, `grimble` or `crunk` `check` in a `pull_request_target` or `workflow_run` workflow that has no `--trust-from`, that names the pull request head, or that passes another `--trust*` flag, and for the `trust` verb. `check --skip-tools` runs no tool and is not judged. It is Unresolved when the ref is an expression or variable that is neither a base nor a head context, or when an `if:` on `head.repo.fork` or `ref_protected` guards the step. A literal ref is taken as protected, since the workflow text cannot show branch protection.

## Why it matters

These workflows run with a write token and secrets. Trust read from the checked-out lock is trust the pull request grants itself; trust read at a protected ref cannot be edited by the pull request.

## Remedy

Run `check --trust-from <protected ref>`, for example the base branch, or `check --skip-tools`.

## Examples

### Fires case 1

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check
```

### Fires case 2

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check --trust-from ${{ github.event.pull_request.head.sha }}
```

### Fires case 3

```yaml expect=fire file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: grimble check --trust-all
```

### Clean case 4

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check --trust-from origin/main
```

### Clean case 5

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check --trust-from ${{ github.event.pull_request.base.ref }}
```

### Clean case 6

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check --skip-tools
```

### Clean case 7

```yaml expect=clean file=.github/workflows/ci.yml
name: ci
on: push
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check
```

### Unresolved case 8

```yaml expect=unresolved file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - run: frob check --trust-from $TRUSTED_REF
```

### Unresolved case 9

```yaml expect=unresolved file=.github/workflows/ci.yml
name: ci
on: pull_request_target
permissions:
  contents: read
jobs:
  check:
    runs-on: ubuntu-latest
    if: github.event.pull_request.head.repo.fork == false
    steps:
      - run: frob check
```
