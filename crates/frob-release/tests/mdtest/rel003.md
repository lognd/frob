# REL003 changelog fragment required

Each block is a `changelog.d` directory. `fragment NAME BODY` writes a fragment
(`-` is an empty body, `@nonascii` a body with a non-ASCII letter); `require ULID` additionally demands that ticket's
fragment, as `check --ticket` does. The known tickets are
01ARZ3NDEKTSV4RRFFQ69G5FAV and 01BX5ZZKBKACTAV9WEVGEMMVRY.

## A required ticket with no fragment fires

```text expect=fire
require 01ARZ3NDEKTSV4RRFFQ69G5FAV
```

## An unknown type fires

```text expect=fire
fragment 01ARZ3NDEKTSV4RRFFQ69G5FAV.improved.md frob: Made it better.
```

## An empty body fires

```text expect=fire
fragment 01ARZ3NDEKTSV4RRFFQ69G5FAV.changed.md -
```

## A ULID that is not a ticket fires

```text expect=fire
fragment 01CZ3NDEKTSV4RRFFQ69G5FAVX.changed.md frob: Changed a thing.
```

## A name that is not a ULID fires

```text expect=fire
fragment notes.changed.md frob: Changed a thing.
```

## A non-ASCII body fires

```text expect=fire
fragment 01ARZ3NDEKTSV4RRFFQ69G5FAV.added.md @nonascii
```

## A near-miss product prefix fires

```text expect=fire
fragment 01ARZ3NDEKTSV4RRFFQ69G5FAV.added.md frobb: Added a thing.
```

## A valid fragment for the required ticket is clean

```text expect=clean
fragment 01ARZ3NDEKTSV4RRFFQ69G5FAV.changed.md frob: Changed a thing.
require 01ARZ3NDEKTSV4RRFFQ69G5FAV
```

## An unprefixed body and a gob fragment are clean

```text expect=clean
fragment 01ARZ3NDEKTSV4RRFFQ69G5FAV.fixed.md Fixed a thing.
fragment 01BX5ZZKBKACTAV9WEVGEMMVRY.added.md gob: Added a gob thing.
```

## No changelog directory and nothing required is clean

```text expect=clean
```
