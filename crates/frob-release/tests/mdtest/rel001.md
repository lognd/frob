# REL001 release without cut

Each block is a small repository. `commit VERSION` commits a root manifest
declaring that workspace version; `tag NAME` makes an annotated tag at the
latest commit with plain tag creation (no cut recorded); `cut NAME VERSION`
makes the tag and records a cut for it, as `frob release cut` does.

## A tag made by plain tag creation fires

```text expect=fire
commit 0.0.1
tag frob-v0.0.1
```

## A grimble tag with no recorded cut fires

```text expect=fire
commit 0.2.0
tag grimble-v0.2.0
```

## A tag whose version differs from the committed workspace version fires

```text expect=fire
commit 0.0.9
cut frob-v0.1.0 0.1.0
```

## A tag made and recorded by release cut is clean

```text expect=clean
commit 0.532.0
cut frob-v0.532.0 0.532.0
cut grimble-v0.532.0 0.532.0
```

## The v1 release tag matches no product prefix and is ignored

```text expect=clean
commit 0.531.0
tag v0.531.0
```
