# REL002 lockstep version mismatch

Each block is a small repository. `workspace VERSION` writes the root
manifest (`workspace -` declares no version); `crate NAME VERSION` writes a
member (`inherit` for `version.workspace = true`); `wheel VERSION` writes a
`pyproject.toml` (`wheel dynamic` for a maturin dynamic version).

## One crate left at an older version fires

```text expect=fire
workspace 0.532.0
crate frob 0.532.0
crate frob-ack 0.531.0
```

## The wheel left at an older version fires

```text expect=fire
workspace 0.532.0
crate frob inherit
wheel 0.531.0
```

## Without a workspace version the straggler is still named

```text expect=fire
workspace -
crate a 0.2.0
crate b 0.2.0
crate c 0.1.0
```

## Every crate at the workspace version is clean

```text expect=clean
workspace 0.532.0
crate frob 0.532.0
crate frob-ack 0.532.0
wheel 0.532.0
```

## Inherited versions and a maturin dynamic wheel are clean

```text expect=clean
workspace 0.532.0
crate frob inherit
crate frob-ack inherit
wheel dynamic
```

## A repository with no wheel metadata is clean

```text expect=clean
workspace 0.532.0
crate frob inherit
```
