# GX019 colour-blind-mode

A game must offer a colour-blind mode for each declared deficiency.

## What it does

Flags a name in `[game] colour_blind_modes` that is not a declared `[palette.modes]` entry. Unresolved (`colour-blind-modes-undeclared`) when the list is empty.

## Why it matters

Colour alone must not carry meaning; a mode needs a palette to switch to.

## Remedy

Declare the palette mode, or remove the name.

## Examples

### A mode without a palette fires

```toml expect=fire file=crunk.toml
[game]
coverage = []
colour_blind_modes = ["deuteranopia"]
```

### A declared palette mode is clean

```toml expect=clean file=crunk.toml
[game]
coverage = []
colour_blind_modes = ["deuteranopia"]

[palette.modes.deuteranopia]
ink = "#ffffff"
```

### No modes listed is unresolved

```toml expect=unresolved file=crunk.toml reason=colour-blind-modes-undeclared
[game]
coverage = []
```
