# GX021 hold-alternative

A hold input needs a non-hold alternative.

## What it does

Flags a `[[game.action]]` with `hold = true` and no `hold_alternative`. Unresolved (`hold-undeclared`) when `hold` is absent.

## Why it matters

Holding a button is impossible for some players.

## Remedy

Declare a toggle or tap alternative.

## Examples

### A hold with no alternative fires

```toml expect=fire file=crunk.toml
[game]
coverage = []

[[game.action]]
id = "sprint"
hold = true
```

### A hold with a toggle is clean

```toml expect=clean file=crunk.toml
[game]
coverage = []

[[game.action]]
id = "sprint"
hold = true
hold_alternative = "toggle"
```

### An undeclared hold is unresolved

```toml expect=unresolved file=crunk.toml reason=hold-undeclared
[game]
coverage = []

[[game.action]]
id = "sprint"
```
