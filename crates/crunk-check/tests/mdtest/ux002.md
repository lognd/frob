# UX002 flow-dead-end

Every state of a flow must lead somewhere, or end the flow on purpose.

## What it does

With `[packs] design_cycle = true`, reads `design/flows/*.flow.toml` and flags each state that has no
outgoing edge. A state named `done`, `end`, `exit`, `complete`, `completed` or `success` (the part after
the colon of `screen:state`) ends the flow on purpose and is not a dead end, and a flow of one state
has nothing to lead to. A project that has not switched the pack on is silent.

## Why it matters

A person who reaches a state with no way out is stuck: no next step, no way back.

## Remedy

Add an edge out of the state, or name it as an ending.

## Examples

### A state with no way out fires

```toml file=design/flows/checkout.flow.toml
name = "checkout"
nodes = ["cart:default", "pay:default"]

[[edges]]
from = "cart:default"
to = "pay:default"
trigger = "click"
```

```toml expect=fire file=crunk.toml
[packs]
design_cycle = true
```

### A flow that ends in a terminal state is clean

```toml file=design/flows/checkout.flow.toml
name = "checkout"
nodes = ["cart:default", "pay:done"]

[[edges]]
from = "cart:default"
to = "pay:done"
trigger = "click"
```

```toml expect=clean file=crunk.toml
[packs]
design_cycle = true
```

### A project that has not opted in is clean

```toml file=design/flows/checkout.flow.toml
name = "checkout"
nodes = ["cart:default", "pay:default"]

[[edges]]
from = "cart:default"
to = "pay:default"
trigger = "click"
```

```toml expect=clean file=crunk.toml
[packs]
design_cycle = false
```
