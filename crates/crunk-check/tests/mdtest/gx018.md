# GX018 remap-coverage

Every input action must be remappable.

## What it does

Flags a `[[game.action]]` declared `remappable = false`. Unresolved (`remap-undeclared`) when the action does not say.

## Why it matters

A player who cannot use the default binding is locked out.

## Remedy

Make the action remappable, or declare it.

## Examples

### A fixed binding fires

```toml expect=fire file=crunk.toml
[game]
coverage = []

[[game.action]]
id = "jump"
remappable = false
```

### A remappable action is clean

```toml expect=clean file=crunk.toml
[game]
coverage = []

[[game.action]]
id = "jump"
remappable = true
```

### An undeclared action is unresolved

```toml expect=unresolved file=crunk.toml reason=remap-undeclared
[game]
coverage = []

[[game.action]]
id = "jump"
```
