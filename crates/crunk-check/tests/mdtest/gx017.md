# GX017 glyph-coverage

Every input action needs a glyph for every supported device.

## What it does

For each `[[game.action]]` and each name in `[game] devices`, flags an action whose `glyphs` list lacks that device. Unresolved (`no-devices`) when actions exist but no devices are declared.

## Why it matters

A prompt that shows a keyboard key to a gamepad player is unreadable.

## Remedy

Add the missing device to the action's `glyphs`, or drop the device.

## Examples

### A missing gamepad glyph fires

```toml expect=fire file=crunk.toml
[game]
coverage = []
devices = ["keyboard", "gamepad"]

[[game.action]]
id = "jump"
glyphs = ["keyboard"]
```

### Glyphs for every device are clean

```toml expect=clean file=crunk.toml
[game]
coverage = []
devices = ["keyboard", "gamepad"]

[[game.action]]
id = "jump"
glyphs = ["keyboard", "gamepad"]
```

### Actions without devices are unresolved

```toml expect=unresolved file=crunk.toml reason=no-devices
[game]
coverage = []

[[game.action]]
id = "jump"
glyphs = ["keyboard"]
```
