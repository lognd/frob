# GX020 subtitle-options

Subtitles need a readable size, a background and speaker labels.

## What it does

Flags `[game.subtitles]` with `size_px` below the strictest profile minimum at 1080p (18 without a profile), `background = false` or `speaker_labels = false`. Unresolved (`subtitles-undeclared`) when coverage lists `subtitle_format` but the table is absent.

## Why it matters

Subtitles are the only access to dialogue for a deaf player.

## Remedy

Raise the size and enable both options.

## Examples

### Tiny subtitles fire

```toml expect=fire file=crunk.toml
[game]
coverage = []

[game.subtitles]
size_px = 12
background = true
speaker_labels = true
```

### Readable subtitles are clean

```toml expect=clean file=crunk.toml
[game]
coverage = []

[game.subtitles]
size_px = 28
background = true
speaker_labels = true
```

### Missing subtitle table is unresolved

```toml expect=unresolved file=crunk.toml reason=subtitles-undeclared
[game]
coverage = ["subtitle_format"]
```
