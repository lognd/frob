# A11Y104 route-change-announced

A client route must set the document title and move focus or announce the change.

## What it does

With `[packs] crunk_web = true`, finds the page routes of the detected frameworks (React Router
and Next.js) and flags one finding per route whose page component and layouts set no document
title (`document.title`, `<title>`, `<Helmet>`, `<Head>`, a metadata export) or, outside Next.js
(which announces its own route changes), move no focus and write no live region (`.focus()`,
`autoFocus`, `aria-live`, `role="status"`, `role="alert"`). The check is lexical over the route's
component files; a route whose sources cannot be read is not judged.

## Why it matters

A client-side navigation does not reload the page, so a screen reader hears nothing and the tab
title stays stale unless the page does that work itself.

## Remedy

Set `document.title` in the route and move focus to its heading, or render a live region that
names the new page.

## Examples

### A route without title or focus fires

```ts expect=fire file=app/routes.ts
import { type RouteConfig, route } from "@react-router/dev/routes";

export default [
  route("silent", "./routes/silent.tsx"),
] satisfies RouteConfig;
```

```tsx file=app/routes/silent.tsx
export default function SilentPage() {
  return <h1>Silent</h1>;
}
```

```json file=package.json
{ "name": "app", "dependencies": { "react-router": "7.0.0", "@react-router/dev": "7.0.0" } }
```

```toml file=crunk.toml
[packs]
crunk_web = true
```

### A route with a title and a focus move is clean

```ts expect=clean file=app/routes.ts
import { type RouteConfig, route } from "@react-router/dev/routes";

export default [
  route("good", "./routes/good.tsx"),
] satisfies RouteConfig;
```

```tsx file=app/routes/good.tsx
import { useEffect, useRef } from "react";

export default function GoodPage() {
  const heading = useRef<HTMLHeadingElement>(null);
  useEffect(() => {
    document.title = "Good";
    heading.current?.focus();
  }, []);
  return <h1 ref={heading} tabIndex={-1}>Good</h1>;
}
```

```json file=package.json
{ "name": "app", "dependencies": { "react-router": "7.0.0", "@react-router/dev": "7.0.0" } }
```

```toml file=crunk.toml
[packs]
crunk_web = true
```
