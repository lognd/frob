# GX016 text-size-at-distance

Text must be large enough for the distance the profile is played at.

## What it does

Scales every text run of every scene to each `[[game.profile]]` and compares it with the profile
minimum: `min_text_px` at 1080p, defaulting to 26 for a console and 18 for a pc, scaled by the
profile height. A font size below the minimum fires outright. A font size that passes is judged by
the drawn glyph height, `[game] glyph_height_pct` percent of the size; without that measurement the
rule is Unresolved (`glyph-height-unmeasured`). A mobile profile with no `min_text_px` has no known
minimum and is Unresolved (`no-minimum-for-kind`).

## Why it matters

Console text is read from a sofa. Text that is legible at a desk is not legible there.

## Remedy

Raise the font size, or lower the claim by declaring a measured `glyph_height_pct`.

## Examples

### A 16 px label on a console fires

```toml
[game]
coverage = []
glyph_height_pct = 90

[[game.profile]]
id = "tv"
kind = "console"
width = 1920
height = 1080
```

```json expect=fire file=design/scenes/menu.scene.json
{
  "viewport": { "width": 1920, "height": 1080 },
  "root": {
    "id": "root",
    "kind": "box",
    "style": { "width": 1920, "height": 1080 },
    "children": [
      { "id": "label", "kind": "text", "text": { "content": "Start", "font_size": 16 }, "style": {} }
    ]
  }
}
```
