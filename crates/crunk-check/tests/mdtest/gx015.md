# GX015 hud-safe-area

A HUD must keep its text and targets inside the safe area of every target profile.

## What it does

For each scene file named `hud` (or ending in `.hud`, `-hud`, `_hud`) and each `[[game.profile]]`,
scales the solved layout to the profile and flags a text run or interactive target that leaves the
safe area. The margin is `safe_area_pct` percent of each edge; it defaults to 5 for a console and
0 otherwise. The rule is Unresolved when a HUD exists but no profile is declared, or when the scene
and the profile differ in aspect ratio, because the layout cannot then be scaled soundly.

## Why it matters

A television may crop the outer edge of the picture; a health bar drawn there is simply gone.

## Remedy

Move the element inside the safe area, for example with container padding.

## Examples

### A button in the corner fires

```toml
[game]
coverage = []

[[game.profile]]
id = "tv"
kind = "console"
width = 1920
height = 1080
```

```json expect=fire file=design/scenes/hud.scene.json
{
  "viewport": { "width": 1920, "height": 1080 },
  "root": {
    "id": "root",
    "kind": "box",
    "style": { "width": 1920, "height": 1080 },
    "children": [
      { "id": "pause", "kind": "box", "interactive": true, "style": { "width": 200, "height": 60 } }
    ]
  }
}
```

### A padded button is clean

```toml
[game]
coverage = []

[[game.profile]]
id = "tv"
kind = "console"
width = 1920
height = 1080
```

```json expect=clean file=design/scenes/hud.scene.json
{
  "viewport": { "width": 1920, "height": 1080 },
  "root": {
    "id": "root",
    "kind": "box",
    "style": { "width": 1920, "height": 1080, "padding": 100 },
    "children": [
      { "id": "pause", "kind": "box", "interactive": true, "style": { "width": 200, "height": 60 } }
    ]
  }
}
```

### A HUD without a profile is unresolved

```toml
[game]
coverage = []
```

```json expect=unresolved file=design/scenes/hud.scene.json reason=no-profiles
{
  "viewport": { "width": 1920, "height": 1080 },
  "root": {
    "id": "root",
    "kind": "box",
    "style": { "width": 1920, "height": 1080 },
    "children": [
      { "id": "pause", "kind": "box", "interactive": true, "style": { "width": 200, "height": 60 } }
    ]
  }
}
```

### A scene with another aspect ratio is unresolved

```toml
[game]
coverage = []

[[game.profile]]
id = "tv"
kind = "console"
width = 1920
height = 1080
```

```json expect=unresolved file=design/scenes/hud.scene.json reason=aspect-mismatch
{
  "viewport": { "width": 800, "height": 800 },
  "root": {
    "id": "root",
    "kind": "box",
    "style": { "width": 800, "height": 800 },
    "children": [
      { "id": "pause", "kind": "box", "interactive": true, "style": { "width": 100, "height": 40 } }
    ]
  }
}
```
