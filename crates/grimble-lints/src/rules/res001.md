# RES001 unpaired-resource-acquisition

An acquire call with no paired release in its scope: the resource is never given back.

## What it does

Fires in TypeScript, TSX, JavaScript and JSX for a call from a fixed table of acquire APIs whose release never appears in the matching scope: `performance.mark` without `performance.clearMarks` in the file, `Map.set` on a receiver built by `new Map()` without `delete` or `clear` on the same receiver in its class or file, and `setTimeout`, `setInterval`, `addEventListener`, `URL.createObjectURL` and `new AbortController()` without their release (`clearTimeout`, `clearInterval`, `removeEventListener`, `URL.revokeObjectURL`, `abort`) in the enclosing class or function. A release in another function or on another receiver does not pair. When the handle is returned, stored, passed on or discarded, a release may live out of sight, so the rule reports Unresolved, never a guessed Warn. Calls inside test bodies are not judged. Other languages are not judged by this rule yet.

## Why it matters

An unreleased timer, listener, mark or cache entry accumulates for the life of the page or process: memory grows, callbacks fire after their owner is gone, and the leak surfaces far from its cause.

## Remedy

Release the resource where it is acquired or where the owner is torn down: `clearTimeout(handle)`, `removeEventListener`, `performance.clearMarks()`, `map.delete(key)`. If another owner releases it, keep the handle in that owner so the pairing is visible.

## Examples

### Fires case 1

```typescript expect=fire file=src/perf.ts
export function measure() {
  performance.mark('start');
}
```

### Fires case 2

```typescript expect=fire file=src/cache.ts
const cache = new Map();

export function put(key: string) {
  cache.set(key, 1);
}
```

### Fires case 3

```typescript expect=fire file=src/timer.ts
export function arm() {
  const t = setTimeout(() => {}, 5);
}
```

### Clean case 4

```typescript expect=clean file=src/perf.ts
export function measure() {
  performance.mark('start');
  performance.clearMarks('start');
}
```

### Clean case 5

```typescript expect=clean file=src/cache.ts
const cache = new Map();

export function put(key: string) {
  cache.set(key, 1);
}

export function drop(key: string) {
  cache.delete(key);
}
```

### Clean case 6

```typescript expect=clean file=src/timer.ts
export function arm() {
  const t = setTimeout(() => {}, 5);
  clearTimeout(t);
}
```

### Unresolved case 7

```typescript expect=unresolved file=src/timer.ts
export function arm() {
  const t = setTimeout(() => {}, 5);
  return t;
}
```
