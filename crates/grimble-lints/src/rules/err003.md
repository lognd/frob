# ERR003 silent-catch-all

A catch-all handler that neither rethrows nor logs the error.

## What it does

Fires in Python, TypeScript and C# for a catch-all handler (`except` or `except Exception`, `catch (e)`, C# `catch` or `catch (Exception)`) whose body is not empty but neither rethrows nor logs: it does something else and the error is gone. An empty body is `ERR001`. A handler that logs, rethrows or catches a specific type is clean. Other languages are not judged by this rule yet.

## Why it matters

A catch-all that quietly carries on turns every bug into silent misbehavior, and the original cause is not recoverable.

## Remedy

Log the error with context, rethrow it, or narrow the handler to the exception types you can actually recover from.

## Examples

### Fires case 1

```python expect=fire file=src/job.py
def run(f):
    try:
        f()
    except Exception:
        x = 1
```

### Fires case 2

```ts expect=fire file=src/job.ts
export function run(f: () => void) {
  try {
    f();
  } catch (e) {
    const x = 1;
  }
}
```

### Clean case 3

```python expect=clean file=src/job.py
def run(f):
    try:
        f()
    except Exception:
        logger.exception('run failed')
```

### Clean case 4

```ts expect=clean file=src/job.ts
export function run(f: () => void) {
  try {
    f();
  } catch (e) {
    console.error(e);
    throw e;
  }
}
```
