# DUP002 arch-renamed-duplicate-code

A block of code copied three or more times with renamed identifiers or the same shape.

## What it does

Fires once for a block of `dup_min_tokens` (default 50) or more tokens that occurs at `dup_min_occurrences` (default 3) or more places in the walk, where the copies are not all token-identical: R2 copies keep the tokens but consistently rename identifiers, R3 copies keep only the token shape with names and literals changed. Exact copies are reported by `DUP001`, and a block reported at a stricter rung is not reported again at a looser one. The default severity is Error and no opt-in knob is needed; the cached window hashes of the clone index make an unchanged tree cost almost nothing, and `frob baseline adopt DUP002` adopts existing clones. `dup_min_tokens = 0` or `dup_min_occurrences` below 2 turns the rule off. A token match is exact, so the rule is never Unresolved.

## Why it matters

A renamed copy hides the clone from a text diff but is still one design maintained in several places.

## Remedy

Extract the shared block into a function or type that the sites call, or tune `[grimble] dup_min_tokens` and `dup_min_occurrences`.

## Examples

### Fires case 1

```rust expect=fire file=src/lib.rs
pub fn first(a: i64, b: i64, c: i64) -> i64 {
    let sum = a + b * c - a;
    let diff = sum * b + c - a;
    let prod = diff * sum + b - c;
    let out = prod + diff * sum - a + b;
    out * 2 + sum - diff
}

pub fn second(a: i64, b: i64, c: i64) -> i64 {
    let s2 = a + b * c - a;
    let d2 = s2 * b + c - a;
    let prod = d2 * s2 + b - c;
    let out = prod + d2 * s2 - a + b;
    out * 2 + s2 - d2
}

pub fn third(a: i64, b: i64, c: i64) -> i64 {
    let s3 = a + b * c - a;
    let d3 = s3 * b + c - a;
    let prod = d3 * s3 + b - c;
    let out = prod + d3 * s3 - a + b;
    out * 2 + s3 - d3
}
```
