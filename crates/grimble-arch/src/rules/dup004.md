# DUP004 arch-structural-duplicate-code

A function in a changed file has the same statement shapes as another function, whatever the names and statement order.

## What it does

When the check has a base ref (`frob check --base <ref>`, which `frob land` passes), `DUP004` fingerprints every function and method outside tests that has `dup_min_tokens` (default 50) or more tokens and at least four statements. A fingerprint is the sorted multiset of statement shapes, where a shape keeps operators, punctuation and keywords and abstracts identifiers to one token and literals to another. Two functions with equal fingerprints are structural clones even when one renames every identifier and reorders its statements, which the token windows of `DUP001` and `DUP002` cannot see. The rule fires once per class that includes a function in a file changed since the merge-base with the base ref, anchored at the first changed member and naming the others; classes made only of unchanged files are left alone, so a land pays only for what it touches. A class whose members keep the same statement order and number `dup_min_occurrences` or more is reported by `DUP002` instead. Without a base ref the rule is not applicable. `dup_min_tokens = 0` turns it off. It covers every language the symbol graph parses with functions: Rust, Python, TypeScript, C#, Java, C, C++, Go and shell. A shape match is exact, so the rule is never Unresolved.

## Why it matters

A copy that was reordered and renamed is still one design maintained in two places, and it is exactly the copy a reviewer does not notice.

## Remedy

Extract the shared statements into one function that both sites call.

## Examples

### Fires case 1

```rust expect=fire file=src/lib.rs
pub fn first(a: i64, b: i64, c: i64) -> i64 {
    let sum = a + b * c - a;
    let diff = sum * b + c - a;
    let prod = diff * sum + b - c;
    let out = prod + diff * sum - a + b;
    out * 2 + sum - diff
}

pub fn second(a: i64, b: i64, c: i64) -> i64 {
    let d2 = a + b * c - a;
    let s2 = d2 * b + c - a;
    let out = prod + d2 * s2 - a + b;
    let prod = s2 * d2 + b - c;
    out * 2 + s2 - d2
}
```

### Clean case 2

```rust expect=clean file=src/lib.rs
pub fn first(a: i64, b: i64, c: i64) -> i64 {
    let sum = a + b * c - a;
    let diff = sum * b + c - a;
    let prod = diff * sum + b - c;
    let out = prod + diff * sum - a + b;
    out * 2 + sum - diff
}

pub fn second(a: i64, b: i64, c: i64) -> i64 {
    if a > b {
        return c;
    }
    let total = a + b + c;
    println!("{total}");
    total
}
```
