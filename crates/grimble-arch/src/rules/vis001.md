# VIS001 arch-wide-visibility

A `pub` function that no other package uses.

## What it does

Fires for a `pub` free function in a Rust file that is not part of the crate's public API (its module chain is not all `pub` and no `pub use` re-exports it) and that no call, reference or import edge from another package reaches. A unit reached from another package only through a May edge, or whose name an unresolved call from another package spells, is Unresolved. Types and methods are not judged, since the graph has no edge for a use in a type position.

## Why it matters

A visibility wider than the uses invites coupling the author never meant to offer, and hides what the real interface is. rustc's `unreachable_pub` lint says the same for a single crate.

## Remedy

Narrow the item to `pub(crate)`, or use it from the package that needs it.

## Examples

### Fires case 1

```rust expect=fire file=src/lib.rs
mod inner {
    pub fn helper() {}
}

pub fn api() {
    inner::helper();
}
```

### Clean case 2

```rust expect=clean file=src/lib.rs
mod inner {
    pub fn helper() {}
}

pub use crate::inner::helper;
```
