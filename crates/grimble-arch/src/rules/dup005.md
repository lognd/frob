# DUP005 arch-structural-duplicate-scan

A function anywhere in the repository has the same statement shapes as another function, whatever the names and statement order.

## What it does

The whole-repo form of `DUP004`, meant for a nightly job rather than a land. It fingerprints every function and method outside tests the way `DUP004` does, but reports every class of two or more functions once, anchored at its first member and naming the others, whether or not any member changed. It is off unless `[grimble] dup_scan = true` or the `GRIMBLE_DUP_SCAN` environment variable is `1`; off, the rule is not applicable, so `frob check` and `frob land` never pay for it. Adopt the clusters that exist by listing the `fingerprint` of each finding under `[rules.DUP005]` in `frob-baseline.toml`: a listed cluster is muted and only a new cluster fails (renaming or moving a member makes a cluster new). A class whose members keep the same statement order and number `dup_min_occurrences` or more is reported by `DUP002` instead. `dup_min_tokens = 0` turns it off. A shape match is exact, so the rule is never Unresolved.

## Why it matters

A copy that was reordered and renamed is still one design maintained in two places, and it is exactly the copy a reviewer does not notice.

## Remedy

Extract the shared statements into one function that both sites call.

## Examples

### Fires case 1

```rust expect=fire file=src/lib.rs
pub fn first(a: i64, b: i64, c: i64) -> i64 {
    let sum = a + b * c - a;
    let diff = sum * b + c - a;
    let prod = diff * sum + b - c;
    let out = prod + diff * sum - a + b;
    out * 2 + sum - diff
}

pub fn second(a: i64, b: i64, c: i64) -> i64 {
    let d2 = a + b * c - a;
    let s2 = d2 * b + c - a;
    let out = prod + d2 * s2 - a + b;
    let prod = s2 * d2 + b - c;
    out * 2 + s2 - d2
}
```

### Clean case 2

```rust expect=clean file=src/lib.rs
pub fn first(a: i64, b: i64, c: i64) -> i64 {
    let sum = a + b * c - a;
    let diff = sum * b + c - a;
    let prod = diff * sum + b - c;
    let out = prod + diff * sum - a + b;
    out * 2 + sum - diff
}

pub fn second(a: i64, b: i64, c: i64) -> i64 {
    if a > b {
        return c;
    }
    let total = a + b + c;
    println!("{total}");
    total
}
```
