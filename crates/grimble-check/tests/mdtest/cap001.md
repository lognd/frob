# CAP001 cap-undeclared

## An ungranted subprocess call fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
=== src/x.py
import subprocess

def go():
    subprocess.run(["ls"])
```

## A granted call is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; may exec; }
node d : trusted { owns "design/**"; }
=== src/x.py
import subprocess

def go():
    subprocess.run(["ls"])
```
