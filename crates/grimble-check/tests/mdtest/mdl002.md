# MDL002 unresolved include

## An include of a missing file fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
include "gone.grmb";
```

## An include of an existing file is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
include "part.grmb";
=== design/part.grmb
grimble = "2";
part of m;
node a : trusted {
}
```
