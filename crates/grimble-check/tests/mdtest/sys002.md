# SYS002 sys-ambiguous-owner

## Two nodes tying on one unit fire

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node b : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
=== src/lib.rs
pub fn run() {}
```

## A more specific selector breaks the tie

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node b : trusted { owns "src/lib.rs::run"; }
node d : trusted { owns "design/**"; }
=== src/lib.rs
pub fn run() {}
```
