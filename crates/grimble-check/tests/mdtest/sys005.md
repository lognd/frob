# SYS005 sys-unmodeled

## A public unit in a modeled selector no node owns fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/owned.rs"; }
node d : trusted { owns "design/**"; }
=== grimble.toml
[grimble]
models = ["design/model.grmb"]
modeled = ['"src/**" & lang(rust)']
=== src/owned.rs
pub fn owned() {}
=== src/loose.rs
pub fn loose() {}
```

## A modeled selector fully owned is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
=== grimble.toml
[grimble]
models = ["design/model.grmb"]
modeled = ['"src/**" & lang(rust)']
=== src/owned.rs
pub fn owned() {}
```
