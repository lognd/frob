# SYS003 sys-binding-conflict

## Two directives naming different nodes fire

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node b : trusted { owns "other/**"; }
node d : trusted { owns "design/**"; }
=== src/lib.rs
// grimble:binds design:node/a
// grimble:binds design:node/b
pub fn run() {}
=== other/x.rs
pub fn x() {}
```

## A dangling directive operand fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
=== src/lib.rs
// grimble:binds design:node/nope
pub fn one() {}
```

## A shape naming several identities fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
contract two { shape "src/lib.rs::Msg"; shape "src/lib.rs::Other"; }
=== src/lib.rs
pub struct Msg;
pub struct Other;
```

## A resolving directive is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
contract one { shape "src/lib.rs::Msg"; }
=== src/lib.rs
// grimble:binds design:node/a
pub struct Msg;
```
