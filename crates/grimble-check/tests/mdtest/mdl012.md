# MDL012 deprecated name

## A reference by a renamed_from name fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node new_name : trusted {
  renamed_from old_name;
}
node b : trusted {
}
flow f : old_name -> b {
  label Public;
}
```

## A reference by the new name is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node new_name : trusted {
  renamed_from old_name;
}
node b : trusted {
}
flow f : new_name -> b {
  label Public;
}
```
