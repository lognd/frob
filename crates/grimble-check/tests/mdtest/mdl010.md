# MDL010 selector empty by construction

## A selector that contradicts itself fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns lang(rust) & lang(python);
}
```

## A satisfiable selector is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted {
  owns lang(rust) & kind(function);
}
=== src/lib.rs
pub fn f() {}
```
