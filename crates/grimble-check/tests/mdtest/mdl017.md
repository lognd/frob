# MDL017 duplicate clause

## A repeated owns clause fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node n : trusted {
  owns "a/**";
  owns "a/**";
}
```

## Distinct owns clauses are clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node n : trusted {
  owns "a/**";
  owns "b/**";
}
```
