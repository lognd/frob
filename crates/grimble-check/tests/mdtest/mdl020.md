# MDL020 include outside

## An include that climbs without outside fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
include "sub/a.grmb";
=== design/sub/a.grmb
grimble = "2";
part of m;
include "../shared.grmb";
=== design/shared.grmb
grimble = "2";
part of m;
```

## An include that climbs with outside is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
include "sub/a.grmb";
=== design/sub/a.grmb
grimble = "2";
part of m;
include "../shared.grmb" outside;
=== design/shared.grmb
grimble = "2";
part of m;
```
