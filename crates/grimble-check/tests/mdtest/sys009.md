# SYS009 sys-flow-end-unbound

## A flow end with no code beside a bound end fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "a/**"; }
node b : trusted { owns "b/**"; }
node d : trusted { owns "design/**"; }
flow half : a -> b {
  producer "a/lib.rs::send";
  consumer "b/lib.rs::absent";
}
=== a/lib.rs
pub fn send() {}
=== b/lib.rs
pub fn recv() {}
```

## A flow with both ends bound is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "a/**"; }
node b : trusted { owns "b/**"; }
node d : trusted { owns "design/**"; }
flow ok : a -> b {
  producer "a/lib.rs::send";
  consumer "b/lib.rs::recv";
}
=== a/lib.rs
pub fn send() {}
=== b/lib.rs
pub fn recv() {}
```
