# MDL015 shadowing

## A reference resolving to a nearer same-named entity fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node cli : trusted {
}
namespace api {
  node cli : trusted {
  }
  flow f : cli -> cli {
    label Public;
  }
}
```

## A reference anchored with :: is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node cli : trusted {
}
namespace api {
  node inner : trusted {
  }
  flow f : ::cli -> inner {
    label Public;
  }
}
```
