# SYS011 sys-vmodel-link-broken

## A ref to a missing heading fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; owns "docs/**"; }
vmodel req_bad { kind artifact; level requirements; ref "docs/spec.md#missing"; }
=== src/lib.rs
pub fn run() {}
=== docs/spec.md
# Intro

text
```

## A runnable naming a non-test unit fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; owns "tests/**"; }
vmodel t_nontest { kind test; level customer_test; runnable "src/lib.rs::run"; }
=== src/lib.rs
pub fn run() {}
=== tests/t.rs
#[test]
fn it_works() {}
```

## Links that resolve are clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; owns "docs/**"; owns "tests/**"; }
vmodel req_ok { kind artifact; level requirements; ref "docs/spec.md#intro"; }
vmodel t_ok { kind test; level customer_test; runnable "tests/t.rs::it_works"; }
=== src/lib.rs
pub fn run() {}
=== docs/spec.md
# Intro

text
=== tests/t.rs
#[test]
fn it_works() {}
```
