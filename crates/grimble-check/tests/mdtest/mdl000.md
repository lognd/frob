# MDL000 lexical or syntax error

A syntax error becomes a hole; a forbidden construct is refused.

## A keyword used as a name fires

```text expect=fire file=design/model.grmb

module m;
node node : trusted {
}
```

```text expect=clean file=design/model.grmb

}
```
