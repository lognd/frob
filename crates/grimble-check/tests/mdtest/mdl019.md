# MDL019 orphan file

## A file reachable from no root fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
=== grimble.toml
[grimble]
models = ["design/model.grmb"]
=== design/stray.grmb
grimble = "2";
part of m;
```

## An included file is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
include "a.grmb";
=== grimble.toml
[grimble]
models = ["design/model.grmb"]
=== design/a.grmb
grimble = "2";
part of m;
```
