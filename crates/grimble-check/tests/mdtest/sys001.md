# SYS001 sys-unowned

## An artifact no node owns fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; }
=== docs/loose.txt
nobody owns this
```

## Every artifact owned is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; owns "docs/**"; owns "grimble.toml"; }
node d : trusted { owns "design/**"; }
=== docs/loose.txt
owned by a
```
