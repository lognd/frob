# SYS010 sys-claim-without-evidence

## A claim at L2 whose evidence is not a test fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; owns "tests/**"; }
claim bad { noflow a -> d; proof L2; evidence tests "src/lib.rs::run"; }
=== src/lib.rs
pub fn run() {}
=== tests/t.rs
#[test]
fn it_works() {}
```

## A claim backed by a test unit is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; }
node d : trusted { owns "design/**"; owns "tests/**"; }
claim good { noflow a -> d; proof L2; evidence tests "tests/t.rs"; }
=== src/lib.rs
pub fn run() {}
=== tests/t.rs
#[test]
fn it_works() {}
```
