# CAP002 cap-declared-unused

## A granted atom never used fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; may exec; may fs.write; }
node d : trusted { owns "design/**"; }
=== src/x.py
import subprocess

def go():
    subprocess.run(["ls"])
```
