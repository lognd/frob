# SYS004 sys-entity-without-code

## An owns clause matching no unit fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; owns "src/gone.rs::x"; }
node d : trusted { owns "design/**"; }
=== src/gone.rs
pub fn y() {}
```

## A flow with both ends empty fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "a/**"; }
node b : trusted { owns "b/**"; }
node d : trusted { owns "design/**"; }
flow bare : a -> b {}
=== a/lib.rs
pub fn send() {}
=== b/lib.rs
pub fn recv() {}
```

## Clauses that match code are clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node a : trusted { owns "src/**"; owns "src/gone.rs::y"; }
node d : trusted { owns "design/**"; }
=== src/gone.rs
pub fn y() {}
```
