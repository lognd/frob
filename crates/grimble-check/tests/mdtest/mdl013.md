# MDL013 malformed exception

## A top-level accept without on fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node cli : trusted {
}
accept SYS004 because="missing on";
```

## An unknown rule id fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
node cli : trusted {
  accept NOPE999 because="unknown rule id";
}
```

## A well-formed accept is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node cli : trusted {
  accept SYS004 because="one-way import by design";
}
accept SYS004 on cli because="also top-level";
```
