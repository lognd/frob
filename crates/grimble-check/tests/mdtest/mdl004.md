# MDL004 unknown pack

## A pack that is not under packs/ fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
pack missing {
  ref "grimble/none";
  version "1.0.0";
}
```

## A model without packs is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
node n : trusted {
}
```
