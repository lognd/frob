# MDL014 V-model construction

## A test vmodel without runnable fires

```text expect=fire file=design/model.grmb
grimble = "2";
module m;
vmodel req {
  kind artifact;
  level requirements;
  ref "docs/design/a.md#req";
}
vmodel t_missing {
  kind test;
  level customer_test;
  verifies req;
}
```

## A paired verifies is clean

```text expect=clean file=design/model.grmb
grimble = "2";
module m;
vmodel req {
  kind artifact;
  level requirements;
  ref "docs/design/a.md#req";
}
vmodel t_ok {
  kind test;
  level customer_test;
  runnable "t.rs::ok";
  verifies req;
}
```
