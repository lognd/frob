# LOG002 no-logging-crate

A program that emits output has no logging crate configured.

## What it does

Fires once per language when a non-exempt file emits output (stdout, stderr or a file) and no file of that language uses a logging crate (`logging`, `structlog`, `loguru`, `tracing`, `log`, `pino`, `winston`, `Serilog`, `Microsoft.Extensions.Logging` and the like, plus `[log] extra_crates`). The sink may be a file, stdout or stderr, but it must be reached through the logging layer.

## Why it matters

Without a logging layer every output site is its own ad-hoc sink, so nothing can be filtered, redirected or silenced in one place.

## Remedy

Add and configure a logging crate in the logging module and route output through it. Agents must obey and not waive the finding. A human who wants no logging layer waives it with `frob:waive LOG002 <reason>`; the reason is required.

## Examples

### Fires case 1

```python expect=fire file=app.py
print("hello")
```

### Clean case 2

```python expect=clean file=app.py
import logging

log = logging.getLogger(__name__)
log.info("hello")
```
