# CFG001 enforcement knob missing from the materialized file

An enforcement knob of a materialized table that the file does not carry fires.

## A file missing knobs fires

```toml expect=fire file=frob.toml
[tickets]
cas_retries = 5
```

## An empty file fires

```toml expect=fire file=frob.toml
# nothing materialized
```

## A file with every knob is clean

```toml expect=clean file=frob.toml
[tickets]
cas_retries = 5
ref = "trunk"

[tickets.lease]
ttl_minutes = 120
```
