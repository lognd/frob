# CFG001 missing-materialized-knob

A materialized config knob is missing from the product config file.

## What it does

Every knob that affects behavior must be written down with its default so no variable is invisible. A missing file counts as every knob missing.

## Why it matters

A knob that is not in the file is invisible to whoever reads the configuration.

## Remedy

Run `frob init` (or `frob config sync`) to add the missing knobs.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
