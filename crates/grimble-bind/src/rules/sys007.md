# SYS007 sys-changed-since-ack

An acked identity changed since its ack.

## What it does

One finding per lock entry with a kind in the message: facet (a Sig, Body, Doc or Attr digest differs from the acked one), gone (the anchor is absent and no rename candidate exists) and scheme (the lock was written under another format version or digest scheme; every entry is stale and `ack --all --reason` re-attests it). Unresolved when a facet is not Exact (F0 or F1 language, a parse hole) or a gone anchor may live on in a unit whose Body is hidden. An entry SYS008 reports is not reported here.

## Why it matters

An acknowledgement vouches for the code as it was reviewed. A changed body, a changed kind, or a vanished symbol voids that.

## Remedy

Re-review the entity and run `grimble ack <entity>` again, or restore the reviewed code.

## Examples

### Fires case 1

```rust expect=fire file=c/lib.rs
pub fn take(x: u32) -> u32 { let mut total = x; for i in 0..x { total = total + i * 2; } if total > 10 { total - 1 } else { total + 3 } }
```

### Clean case 2

```rust expect=clean file=c/lib.rs
pub fn take(x: u32) -> u32 { let mut total = x; for i in 0..x { total = total + i * 2; } if total > 10 { total - 1 } else { total + 1 } }
```
