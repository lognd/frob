# SYS005 sys-unmodeled

A public unit in a modeled selector that no node owns.

## What it does

Opt-in through `[grimble] modeled`: fires for a public unit selected at Must that is foreign. Effects are not consulted yet (no effects query exists). Unresolved when visibility is unknown (F0 and F1 languages) or the owner is May only; with every selected unit unmeasurable the rule examined nothing and is required-Unresolved (vacuous). Error under `[grimble] strict`.

## Why it matters

Under a `modeled` selector the model is meant to be complete. A file there that no node owns is a promise the model does not keep.

## Remedy

Add the file to a node's `owns`, or narrow `[grimble] modeled`.

## Examples

### Fires case 1

```grmb expect=fire file=design/m.grmb config="modeled"
grimble = "2";
module m;

node a : trusted {
  owns "src/lib.rs";
}
node d : trusted {
  owns "a/**";
  owns "b/**";
  owns "tests/**";
  owns "docs/**";
  owns "design/**";
}
```

### Clean case 2

```grmb expect=clean file=design/m.grmb config="modeled"
grimble = "2";
module m;

node a : trusted {
  owns "src/**";
}
node d : trusted {
  owns "a/**";
  owns "b/**";
  owns "tests/**";
  owns "docs/**";

```
