# CAP004 cap-excuse-masks-use

A template excuse covers a unit that uses the excused capability.

## What it does

Fires per node and atom when a `template` entity says `excuse ATOM for SEL because="..."` and code a node owns, inside the files `SEL` selects, observably uses `ATOM` (binding.md 7.2 item 3). An excuse says an atom does not apply to generated or special code; it is never evidence that the code does not use it. A certain use is an Error and the cell stays a use, never `excused`. A use through an unresolved receiver, or in code the node owns only at May, is Unresolved instead. A use reported here is not also reported as CAP001.

## Why it matters

If an excuse could hide a use, writing one would be a way to silence the capability matrix without changing the code.

## Remedy

Delete the excuse or narrow its selector so it no longer covers the using code, or grant the atom with a `may` clause.

## Examples

### Fires case 1

```grmb expect=fire file=design/m.grmb config="py"
grimble = "2";
module m;

template gen {
  excuse net.listen for "src/x.py" because="generated stubs never bind a socket";
}
node a : trusted {
  owns "src/x.py";
  may fs.read;
  may exec;
  may net.listen;
}
node d : trusted {
  owns "design/**";
}
```

### Clean case 2

```grmb expect=clean file=design/m.grmb config="py"
grimble = "2";
module m;

template gen {
  excuse net.listen for "src/other/**" because="generated stubs never bind a socket";
}
node a : trusted {
  owns "src/x.py";
  may fs.read;
  may exec;
  may net.listen;
}
node d : trusted {
  owns "design/**";
}
```
