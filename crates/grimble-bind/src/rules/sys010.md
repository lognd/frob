# SYS010 sys-claim-without-evidence

A claim above proof level L1 has no test evidence.

## What it does

Fires when the evidence rows of a non-assumed claim at L2 or above are empty or none is a test unit. Test units are recognised by path and qualified name (no `test_items` query exists yet). Unresolved when the evidence is May only or hidden.

## Why it matters

A claim at a proof level needs evidence that exists and sits where evidence can sit. A claim whose evidence is missing proves nothing.

## Remedy

Point the evidence at a test or document that exists, or lower the proof level.

## Examples

### Fires case 1

```grmb expect=fire file=design/m.grmb
grimble = "2";
module m;

node a : trusted {
  owns "src/**";
  owns "a/**";
  owns "b/**";
}
node d : trusted {
  owns "design/**";
  owns "docs/**";
  owns "tests/**";
}
claim bad {
  noflow a -> d;
  proof L2;
  evidence tests "src/lib.rs::run";
}
```

### Clean case 2

```grmb expect=clean file=design/m.grmb
grimble = "2";
module m;

node a : trusted {
  owns "src/**";
  owns "a/**";
  owns "b/**";
}
node d : trusted {
  owns "design/**";
  owns "docs/**";
  owns "tests/**";
}
claim good {
  noflow a -> d;
  proof L2;
  evidence tests "tests/t.rs";
}
```
