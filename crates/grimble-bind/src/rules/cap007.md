# CAP007 cap-grant-expired

A `may` grant has expired: its `until=` date has passed.

## What it does

Fires per `may ATOM ... until=YYYY-MM-DD` clause on a node when the date is before today. The message names the date. An expired grant also stops covering any use, so CAP001 reports the uses it used to allow.

## Why it matters

A grant given for a bounded time (a migration, an incident) must not silently become permanent.

## Remedy

Remove the grant, or renew the date in a reviewed change.

## Examples

### Fires case 1

```grmb expect=fire file=design/m.grmb
grimble = "2";
module m;

node a {
  owns "src/**";
  may fs.read at "src/**" until=2020-01-01;
}
```

### Clean case 2

```grmb expect=clean file=design/m.grmb
grimble = "2";
module m;

node a {
  owns "src/**";
  may fs.read at "src/**" until=2999-01-01;
}
```
