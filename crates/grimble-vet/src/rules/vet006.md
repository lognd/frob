# VET006 yanked

A locked version that was yanked from the registry.

## What it does

Fires for each vetted external package whose locked version the metadata file (`.grimble/vet-meta.toml`) marks `yanked = true`. Not applicable without the metadata file.

## Why it matters

A yank means the authors withdrew the release, usually for a security or soundness defect; new resolutions can no longer pick it.

## Remedy

Update the package to a release that is not yanked.

## Examples

### Fire case 1

```toml expect=fire file=Cargo.lock config="meta=yanked"
version = 4

[[package]]
name = "app"
version = "0.1.0"
dependencies = ["pkg"]

[[package]]
name = "pkg"
version = "1.0.0"
source = "registry+https://github.com/rust-lang/crates.io-index"
```

### Clean case 2

