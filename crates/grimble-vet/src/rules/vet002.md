# VET002 advisory

A locked version that a RustSec advisory affects.

## What it does

Fires for each external locked package whose version an advisory in the offline snapshot (`.grimble/advisory-db`) affects; the message carries the advisory id and the fixed version requirements. Not applicable when the snapshot directory is absent.

## Why it matters

A known vulnerability in a locked version ships to every user of the build.

## Remedy

Update the package to a fixed version named in the message, or replace the crate.

## Examples

### Fire case 1

```toml expect=fire file=Cargo.lock config="advisory"
version = 4

[[package]]
name = "app"
version = "0.1.0"
dependencies = ["badcrate"]

[[package]]
name = "badcrate"
version = "1.1.0"
source = "registry+https://github.com/rust-lang/crates.io-index"
```
