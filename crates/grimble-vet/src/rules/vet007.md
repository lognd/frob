# VET007 maintenance

A locked crate with no release within the maintenance horizon.

## What it does

Fires for each vetted external package whose `last_release` in `.grimble/vet-meta.toml` is more than `policy.max_age_days` (default 730) before the file's `as_of` date. A package on the vet allowlist is exempt. Not applicable without the metadata file or a valid `as_of`.

## Why it matters

An unmaintained dependency receives no fixes, so every later vulnerability in it stays open.

## Remedy

Move to a maintained alternative, or vet the crate on the allowlist after review.

## Examples

### Fire case 1

```toml expect=fire file=Cargo.lock config="meta=stale"
version = 4

[[package]]
name = "app"
version = "0.1.0"
dependencies = ["pkg"]

[[package]]
name = "pkg"
version = "1.0.0"
source = "registry+https://github.com/rust-lang/crates.io-index"
```
