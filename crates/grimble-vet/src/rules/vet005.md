# VET005 licence

A locked package whose licence is missing or outside the policy.

## What it does

Fires for each vetted external package whose SPDX licence expression in `.grimble/vet-meta.toml` cannot be satisfied with `policy.allowed_licenses`, or that declares no licence. An `OR` expression passes when any alternative is allowed, an `AND` expression only when all are. A package on the vet allowlist is exempt. Not applicable without the metadata file or without `policy.allowed_licenses`.

## Why it matters

A dependency under a licence the project cannot ship under is a legal defect that surfaces late.

## Remedy

Replace the crate, obtain a different licence from its authors, or vet it on the allowlist after review.

## Examples

### Fire case 1

```toml expect=fire file=Cargo.lock config="meta=gpl"
version = 4

[[package]]
name = "app"
version = "0.1.0"
dependencies = ["pkg"]

[[package]]
name = "pkg"
version = "1.0.0"
source = "registry+https://github.com/rust-lang/crates.io-index"
```
