# VET008 typosquat

A locked crate name one edit away from a well-known crate.

## What it does

Fires for each vetted external package whose name differs by one insertion, deletion, substitution or adjacent swap from a popular crate (a built-in list plus the names on the vet allowlist) without being that crate. A package on the vet allowlist is exempt.

## Why it matters

Squatting a near-miss name is the common way to land malicious code in a build.

## Remedy

Check the dependency name for a typo; if the crate is genuine, add it to the allowlist.

## Examples

### Fire case 1

```toml expect=fire file=Cargo.lock
version = 4

[[package]]
name = "app"
version = "0.1.0"
dependencies = ["serd"]

[[package]]
name = "serd"
version = "1.0.0"
source = "registry+https://github.com/rust-lang/crates.io-index"
```

### Fire case 2
