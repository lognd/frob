# GMM001 gamma-one

Fixture rule of the product_rules test.

## What it does

Flags a product that holds no item.

## Why it matters

It keeps the fixture honest.

## Remedy

Add an item.

## Examples

### No item fires

```rust expect=fire file=src/lib.rs
fn f() {}
```

### An item is clean

```rust expect=clean file=src/lib.rs
// item
fn f() {}
```
