# BET001 beta-one

Fixture rule of the product_rules test.

## What it does

Flags the word `bad` in a file.

## Why it matters

It keeps the fixture honest.

## Remedy

Remove the word.

## Examples

### A bad word fires

```rust expect=fire file=src/lib.rs
// bad
fn f() {}
```

### No bad word is clean

```rust expect=clean file=src/lib.rs
fn f() {}
```
