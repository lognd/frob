# EXC005 accept-not-attested

An accept directive's bound symbol changed since it was attested.

## What it does

`frob.lock` holds the digest recorded when the accept was attested. The bound symbol's body digest differs, or no entry exists (unattested), so the acceptance may no longer describe the code.

## Why it matters

An acceptance of code that changed is an acceptance of something nobody read.

## Remedy

Re-read the symbol and run `frob ack <symref>` with a reason.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
