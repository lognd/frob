# COV001 untested-public-function

A public function or method has no test that reaches it.

## What it does

The symbol graph lists the public functions and methods. A test (a function the `frob-tests` catalog recognises) reaches one when the call graph, or the unique-name call scan of `frob-tests`, links the test to it, or when a `frob:tests` directive names the pair. Trait-impl members and items in test files are not checked. The finding is located on the function. When the reach cannot be decided (a call through a dynamic edge, or a file parsed only partially) the finding is unresolved, not a pass.

## Why it matters

A public function no test reaches can change behavior with nothing to notice it.

## Remedy

Add a test, or bind an existing one with `frob:tests <test>` above the function.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
/// Doubles.
pub fn double(x: i32) -> i32 { x * 2 } // warn: COV001
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
/// Doubles.
pub fn double(x: i32) -> i32 { x * 2 }

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn doubles() { assert_eq!(double(2), 4); }
}
```
