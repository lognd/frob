# EXC001 exception-reason-rejected

An accept or defer directive carries a reason the checker rejects.

## What it does

The `because` text failed `gob_rules::check_reason`: too short, a banned phrase, a restated rule id or a repeated word. The exception still suppresses its finding so the gate fails on this rule alone.

## Why it matters

A throwaway reason defeats the point of recording one.

## Remedy

Name an ADR, a style anchor or a real one-sentence reason.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
