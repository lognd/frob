# COV005 unit-cases-below-minimum

A scope holds fewer unit test functions than the minimum the `[testing]` table requires.

## What it does

Each `[[testing.threshold]]` entry names a `scope` (a path glob, or a directory prefix) and a `min_unit_cases` count. The rule counts the test functions the symbol graph finds in files of the scope and fires when the count is under the minimum. The finding names the scope, the count, the minimum and the shortfall. A scope that is not a valid glob is unresolved: nothing was measured. A count at or above the minimum passes.

## Why it matters

A floor on test count keeps a scope from shipping with no tests at all, which line coverage alone cannot always show.

## Remedy

Add unit tests to the scope, or lower the minimum with a reason in review.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
