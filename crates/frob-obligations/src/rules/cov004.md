# COV004 coverage-below-threshold

Measured coverage of a scope is under the minimum the `[coverage]` table requires.

## What it does

Each `[[coverage.threshold]]` entry names a `scope` (a path glob, or a directory prefix) and a minimum `line` and/or `branch` percent. The rule reads the lcov report named by `report` (default `lcov.info`), sums the hit and found counts of every file in the scope, and fires when the measured percent is under the minimum. The finding names the scope, the measured value and the required value. When the report is missing or unreadable, no file of the scope appears in it, or it holds no branch data for a branch minimum, the finding is unresolved: nothing was measured.

## Why it matters

A coverage floor only protects the codebase if it is enforced where the other gates run.

## Remedy

Add tests for the scope until the measured value reaches the minimum, regenerate the report, or lower the minimum with a reason in review.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
