# INV002 forbidden-import

A file imports something the `[invariants]` table forbids.

## What it does

An entry of `forbid_imports` (`from`, `to`, `reason`) forbids every file matching `from` from importing a path starting with `to`. The finding names the import and the reason. An entry whose glob does not compile is reported as an unresolved finding.

## Why it matters

Architecture boundaries erode silently unless a gate holds them.

## Remedy

Remove the import, or accept the finding at file level with a reason if the boundary does not apply.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
