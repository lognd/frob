# DOC007 orphan-doc-page

A document under `docs/` that no chain of markdown links from the docs index or a root page reaches.

## What it does

Builds the link graph of every tracked markdown file and walks it from the roots: `docs/README.md` and every markdown file outside `docs/` (the repository README, crate READMEs). A link to a directory counts as a link to its `README.md` or `index.md`; external links, anchors alone and links inside code do not count. A page under `docs/` the walk never reaches is reported on its first line. Generated pages, `historical` pages and `superseded-by` pages are exempt. Broken links and anchors are `DOC002`; this rule only reads the links that resolve.

The rule is a heuristic: a page reached only by a tool, a build step or a non-markdown reference looks orphaned. The finding says so, and a `frob:waive DOC007` on the page carries the reason.

## Why it matters

A page nobody links to is never found, never reviewed and rots; the docs index is the only way a reader knows a document exists.

## Remedy

Link the page from the docs index or from a page that is itself reachable; move it out of `docs/` if it is not documentation; mark it `historical` or `superseded-by` if it is retired; or waive the finding with the reason the page needs no inbound link.

## Examples

### A page nothing links to fires

```markdown expect=fire file=docs/README.md
# Index

Status: current

[a](a.md)
```

```markdown expect=fire file=docs/lost.md
# Lost <!-- error: DOC007 -->

Status: current
```

```markdown file=docs/a.md
# A

Status: current
```

### A page linked from the index is clean

```markdown expect=clean file=docs/README.md
# Index

Status: current

[a](a.md)
```

```markdown file=docs/a.md
# A

Status: current
```

### A page reached through a directory link is clean

```markdown expect=clean file=docs/README.md
# Index

Status: current

[guide](guide/)
```

```markdown file=docs/guide/README.md
# Guide

Status: current
```

### A historical page is exempt

```markdown expect=clean file=docs/README.md
# Index

Status: current
```

```markdown file=docs/old.md
# Old

Status: historical
```
