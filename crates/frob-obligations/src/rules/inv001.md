# INV001 invariant-without-anchor

An invariants document has no `frob:invariant` directive in code.

## What it does

Each `invariants/<slug>.md` file must be upheld somewhere: a `frob:invariant <slug>` directive (slug is the file stem) in code or tests anchors it.

## Why it matters

An invariant no code claims to enforce is documentation that nothing checks.

## Remedy

Add the directive where the invariant is enforced, or remove the document.

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
