# COV003 tests-names-missing-test

Alias of TEST001; never emitted by this crate.

## What it does

A `frob:tests` directive naming a missing test is reported once, as `TEST001`, owned by `frob-tests`. This id stays declared so references to it resolve, but no finding carries it: the registry has no duplicate finding for one problem.

## Why it matters

One problem gets one finding.

## Remedy

Fix the symref or remove the directive (see TEST001).

## Examples

### A violating case fires

```rust expect=fire file=src/lib.rs
pub fn placeholder() {}
```

### A conforming case is clean

```rust expect=clean file=src/lib.rs
pub fn placeholder() {}
```
