# COV005 unit cases below minimum

## Fires when a scope holds fewer test functions than the minimum

```toml expect=fire file=frob.toml
# error: COV005
[[testing.threshold]]
scope = "src"
min_unit_cases = 3
```

```rust file=src/a.rs
#[cfg(test)]
mod tests {
    #[test]
    fn one() {}
}
```

## Is clean when the minimum is met

```toml expect=clean file=frob.toml
[[testing.threshold]]
scope = "src"
min_unit_cases = 1
```

```rust file=src/a.rs
#[cfg(test)]
mod tests {
    #[test]
    fn one() {}
}
```
