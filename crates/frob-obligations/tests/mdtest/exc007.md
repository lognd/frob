# EXC007 defer pointing at a missing ticket

## Fires on an unknown ticket

/* frob:defer COV001 because="split after the parser lands" ticket=01J9QKX3M8Z4T7N2V5B6C0D1E2 */ // error: EXC007

```

## Clean when the ticket exists

/* frob:defer COV001 because="split after the parser lands" ticket={{OPEN}} */

```
