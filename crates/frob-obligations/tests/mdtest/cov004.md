# COV004 coverage below threshold

## Fires when measured line coverage is under the minimum

```toml expect=fire file=frob.toml
# error: COV004
[[coverage.threshold]]
scope = "src"
line = 90
```

```text file=lcov.info
SF:src/a.rs
DA:1,1
DA:2,0
end_of_record
```

## Is clean when the minimum is met

```toml expect=clean file=frob.toml
[[coverage.threshold]]
scope = "src"
line = 50
```

```text file=lcov.info
SF:src/a.rs
DA:1,1
DA:2,0
end_of_record
```

## Reports a missing report as unresolved

```toml expect=unresolved file=frob.toml
[[coverage.threshold]]
scope = "src"
line = 50
```
