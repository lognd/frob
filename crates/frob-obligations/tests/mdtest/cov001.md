# COV001 public functions no test reaches

## Fires on an untested public function

```rust expect=fire file=src/lib.rs
/// Doubles.
pub fn double(x: i32) -> i32 { x * 2 } // warn: COV001
```

## Fires on an untested public method

```rust expect=fire file=src/lib.rs
/// A thing.
pub struct S;

impl S {
    /// Makes one.
    pub fn make() -> S { S } // warn: COV001
}
```

## Clean when a test calls it, even inside a macro

```rust expect=clean file=src/lib.rs
/// Doubles.
pub fn double(x: i32) -> i32 { x * 2 }

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn doubles() { assert_eq!(double(2), 4); }
}
```

## Clean when a test reaches it through a helper

```rust expect=clean file=src/lib.rs
/// Entry point.
pub fn run() -> i32 { helper() }

fn helper() -> i32 { 1 }

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn runs() { assert_eq!(run(), 1); }
}
```

## Clean when a frob:tests directive names it

```rust expect=clean file=src/lib.rs
/// Doubles.
/* frob:tests tests::elsewhere */
pub fn double(x: i32) -> i32 { x * 2 }
```

## Clean for private functions and test files

```rust expect=clean file=src/lib.rs
fn private() {}

pub(crate) fn crate_only() {}
```

## Language matrix

One untested-public-callable case per matrix cell (docs/design/testing.md section 4). The
expected class of each cell is derived from the rule's needs (test items, F2) and the
capability matrix. The C#, text and island cells are allowlisted matrix gaps: the pipeline disagrees with the derivation.

```rust expect=fire cell=rust parity=untested file=src/lib.rs
/// Doubles.
pub fn double(x: i32) -> i32 { x * 2 } // warn: COV001
```

```python expect=fire cell=python parity=untested file=app.py
def double(x):
    return x * 2
```

```typescript expect=fire cell=typescript parity=untested file=app.ts
export function double(x: number): number { return x * 2; }
```

# Notes
