# EXC017 native suppression of a tool-bound rule

The corpus runner binds `clippy::unwrap_used` to COV001 and `unpinned-uses` to CI001 through a `[[check.tool]]` `id_map`.

## Fires on an allow attribute with no exception

```rust expect=fire
#[allow(clippy::unwrap_used)] // warning: EXC017
pub fn f() {}
```

## Fires on a zizmor ignore comment with no exception

```yaml expect=fire file=.github/workflows/ci.yml
on: push
jobs:
  a:
    steps:
      - uses: actions/checkout@v4 # zizmor: ignore[unpinned-uses] // warning: EXC017
```

## Clean when a frob accept covers the mapped rule

```rust expect=clean
/* frob:accept COV001 because="the unwrap is on a value built two lines above" */
#[allow(clippy::unwrap_used)]
pub fn f() {}
```

## Clean when the suppressed id is not bound to a frob rule

```rust expect=clean
#[allow(clippy::too_many_lines)]
pub fn f() {}
```
