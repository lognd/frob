# DOC001 undocumented public items

## Fires on a public function and a public struct

```rust expect=fire
pub fn bare() {} // warn: DOC001
/// Documented.
pub struct Documented; 
pub struct Bare; // warn: DOC001
```

## Clean when documented or not public

```rust expect=clean
/// Documented.
pub fn documented() {}

#[doc = "Documented by attribute."]
pub fn by_attribute() {}

/// Documented, with an attribute between.
#[inline]
pub fn with_attribute() {}

fn private() {}

pub(crate) fn crate_visible() {}

/// A type.
pub struct T;

impl std::fmt::Display for T {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result { f.write_str("t") }
}
```
