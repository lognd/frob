# DOC001 undocumented public items

## Fires on a public function and a public struct

```rust expect=fire
pub fn bare() {} // warn: DOC001
/// Documented.
pub struct Documented; 
pub struct Bare; // warn: DOC001
```

## Clean when documented or not public

```rust expect=clean
/// Documented.
pub fn documented() {}

#[doc = "Documented by attribute."]
pub fn by_attribute() {}

/// Documented, with an attribute between.
#[inline]
pub fn with_attribute() {}

fn private() {}

pub(crate) fn crate_visible() {}

/// A type.
pub struct T;

impl std::fmt::Display for T {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result { f.write_str("t") }
}
```

## C# members need a /// XML doc comment

```csharp expect=fire file=Ship.cs
public class Ship // warn: DOC001
{
    /// <summary>Doubles.</summary>
    /// <param name="n">The input.</param>
    /// <returns>Twice n.</returns>
    public int Thrust(int n) { return n * 2; }

    public int Drift(int n) { return n; } // warn: DOC001
}
```

## C# inheritdoc and documented types are clean

```csharp expect=clean file=Ship.cs
/// <summary>A ship.</summary>
public class Ship : IShip
{
    /// <inheritdoc/>
    public int Thrust(int n) { return n * 2; }

    /// <summary>Private helper is not checked.</summary>
    private int Hidden() { return 1; }

    private int Plain() { return 2; }
}
```
