# DOC002 broken markdown links

## Fires on a missing file

```markdown expect=fire
# Title

See [gone](missing.md). <!-- error: DOC002 -->
```

## Fires on a missing heading in another file

```markdown expect=fire
# Title

See [it](exists.md#no-such-heading). <!-- error: DOC002 -->
```

## Fires on a missing heading in the same file

```markdown expect=fire
# Title

Jump [up](#nowhere). <!-- error: DOC002 -->
```

## Fires on a path that leaves the repository

```markdown expect=fire
# Title

See [out](../../etc/passwd). <!-- error: DOC002 -->
```

## Fires on a root-relative missing file

```markdown expect=fire file=docs/a.md
# Title

See [top](/missing/top.md). <!-- error: DOC002 -->
```

## Clean for existing files and headings

```markdown expect=clean
# Title

See [it](exists.md), [that](exists.md#present-heading), [me](#title),
[itself](case.md#title) and [a dir](.).
```

## Clean for external links, code and fences

````markdown expect=clean
# Title

[web](https://example.com/missing.md) and [mail](mailto:a@example.com)
and `[code](missing.md)` stay quiet.

```text
[fenced](missing.md)
```
````

## Clean for links relative to the file directory

```markdown expect=clean file=docs/a.md
# Title

See [sibling](a.md) and [up](../exists.md).
```
