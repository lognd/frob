# DOC002 broken markdown links

## Fires on a missing file

```markdown expect=fire
# Title

See [gone](missing.md). <!-- error: DOC002 -->
```

## Fires on a missing heading in another file

```markdown expect=fire
# Title

See [it](exists.md#no-such-heading). <!-- error: DOC002 -->
```

```markdown file=exists.md
# Present heading
```

## Fires on a missing heading in the same file

```markdown expect=fire
# Title

Jump [up](#nowhere). <!-- error: DOC002 -->
```

## Fires on a path that leaves the repository

```markdown expect=fire
# Title

See [out](../../etc/passwd). <!-- error: DOC002 -->
```

## Fires on a root-relative missing file

```markdown expect=fire file=docs/a.md
# Title

See [top](/missing/top.md). <!-- error: DOC002 -->
```

## Unresolved when the markdown parsed partially

A table row with an unescaped pipe inside a code span splits mid-span and leaves a parse hole, so a
link beside it cannot be decided.

```markdown expect=unresolved
# Title

| col | other |
| --- | --- |
| `a||b` | [gone](missing.md) |
```

## Language matrix

One case per matrix cell (docs/design/testing.md section 4). The expected class of each cell is
derived from the rule's needs and the capability matrix; a block that contradicts it fails the
matrix check.

```rust expect=clean cell=rust file=src/lib.rs
/// Documented.
pub fn a() {}
```

```python expect=clean cell=python file=app.py
def a():
    pass
```

```typescript expect=clean cell=typescript file=app.ts
function a() {}
```

```csharp expect=clean cell=csharp file=App.cs
class A {}
```

```markdown expect=fire cell=markdown file=notes.md
# Title

See [gone](missing.md). <!-- error: DOC002 -->
```

```text expect=clean cell=text file=notes.txt
See [gone](missing.md).
```

```text expect=notapplicable cell=binary reason=binary file=logo.png
See [gone](missing.md).
```

```text expect=clean cell=island file=notes.xyz
See [gone](missing.md).
```
