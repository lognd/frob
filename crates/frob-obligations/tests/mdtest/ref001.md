# REF001 dangling ticket references

## Fires on an unknown full ULID

```rust expect=fire
/* frob:ticket 01J9QKX3M8Z4T7N2V5B6C0D1E2 */ // error: REF001
fn a() {}
```

## Fires on an unknown v1 alias, in ticket and todo

```rust expect=fire
/* frob:ticket T-9999 */ // error: REF001
fn a() {}
/* frob:todo T-9998 later */ // error: REF001
fn b() {}
```

## Clean for open and done tickets

```rust expect=clean
/* frob:ticket {{OPEN}} */
fn a() {}
/* frob:ticket {{DONE}} */
fn b() {}
```

## Unresolved for a file type no scanner reads

The rule cannot examine an opaque text file, so it says so instead of passing.

```text expect=unresolved file=notes.xyz
TODO this file is never scanned
```

## Language matrix

One case per matrix cell (docs/design/testing.md section 4). The expected class of each cell is
derived from the rule's needs and the capability matrix; a block that contradicts it fails the
matrix check.

```rust expect=fire cell=rust parity=dangling file=src/lib.rs
/* frob:ticket T-9999 */ // error: REF001
fn a() {}
```
