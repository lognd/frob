# REF001 dangling ticket references

## Fires on an unknown full ULID

```rust expect=fire
/* frob:ticket 01J9QKX3M8Z4T7N2V5B6C0D1E2 */ // error: REF001
fn a() {}
```

## Fires on an unknown v1 alias, in ticket and todo

```rust expect=fire
/* frob:ticket T-9999 */ // error: REF001
fn a() {}
/* frob:todo T-9998 later */ // error: REF001
fn b() {}
```

## Clean for open and done tickets

```rust expect=clean
/* frob:ticket {{OPEN}} */
fn a() {}
/* frob:ticket {{DONE}} */
fn b() {}
```
