# INV002 forbidden imports

## Fires on a crate-name entry

```rust expect=fire file=src/a.rs config="forbid_imports = [{ from = 'src', to = 'gob_rules', reason = 'layering' }]"
use gob_rules::Finding; // error: INV002
fn a() {}
```

## Fires on a glob entry and a module prefix

```rust expect=fire file=crates/x/src/a.rs config="forbid_imports = [{ from = 'crates/*/src/**', to = 'crate::cache', reason = 'cache is internal' }]"
use crate::cache::Store; // error: INV002
fn a() {}
```

## Fires for the hyphenated crate spelling

```rust expect=fire file=src/a.rs config="forbid_imports = [{ from = 'src', to = 'gob-rules', reason = 'layering' }]"
use gob_rules::Finding; // error: INV002
fn a() {}
```

## Reports an invalid glob as unresolved

```rust expect=fire file=src/a.rs config="forbid_imports = [{ from = 'src/[', to = 'x', reason = 'bad glob' }]"
fn a() {}
```

## Clean for other files and other targets

```rust expect=clean file=src/a.rs config="forbid_imports = [{ from = 'crates/other/**', to = 'gob_rules', reason = 'layering' }, { from = 'src', to = 'gob_rules_extra', reason = 'other crate' }]"
use gob_rules::Finding;
fn a() {}
```
