# DOC003 doc status header

## A document without a status fires

```markdown expect=fire file=docs/design/a.md
# Title <!-- warn: DOC003 -->

No header here.
```

## A status outside the vocabulary fires

```markdown expect=fire file=docs/design/a.md
# Title

Status: DRAFT <!-- warn: DOC003 -->
Owner: frob
```

## A superseded-by naming a missing document fires

```markdown expect=fire file=docs/design/a.md
# Title

Status: superseded-by `gone.md` <!-- warn: DOC003 -->
```

## A status in the vocabulary is clean

```markdown expect=clean file=docs/design/a.md
# Title

Status: current
Owner: frob
```

## A superseded-by naming an existing document is clean

```markdown expect=clean file=docs/design/a.md
# Title

Status: superseded-by `b.md`
```

```markdown file=docs/design/b.md
# Newer

Status: current
```
