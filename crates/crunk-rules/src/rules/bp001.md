# BP001 media-query-off-breakpoints

Media queries use the declared breakpoints. Each block is one source file in a project whose
`crunk.toml` is the default preset plus `[breakpoints]` sm 640, md 768, lg 1024 (`config=breakpoints`).

## What it does

Flags an `@media` `min-width` or `max-width` px value that is not a declared breakpoint. A
declared breakpoint minus 0.02px (Tailwind's max-width idiom) is accepted. A query with no literal
width is exempt. A project that declares no `[breakpoints]` has the family off: the rule is then
inapplicable and the skip is reported.

## Why it matters

A breakpoint nobody declared is a layout change that no design review, token or other media query
knows about; the page works at 850px for one component and not for its neighbour.

## Remedy

Use a declared breakpoint, or add the width to `[breakpoints]`.

## Examples

### A min-width off the declared breakpoints fires

```css expect=fire config=breakpoints file=styles/app.css
@media (min-width: 850px) {
  .a {
    margin: 0;
  }
}
```

### A declared breakpoint is clean

```css expect=clean config=breakpoints file=styles/app.css
@media (min-width: 768px) {
  .a {
    margin: 0;
  }
}
```

### The minus 0.02px idiom is clean

```css expect=clean config=breakpoints file=styles/app.css
@media (max-width: 767.98px) {
  .a {
    margin: 0;
  }
}
```

### A query without a literal width is exempt

```css expect=clean config=breakpoints file=styles/app.css
@media (prefers-reduced-motion: reduce) {
  .a {
    margin: 0;
  }
}
```
