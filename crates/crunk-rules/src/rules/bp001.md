# BP001 media-query-off-breakpoint

Media query widths must be declared breakpoints. These blocks run in a project declaring `[breakpoints]` sm=640, md=768 and lg=1024.

## What it does

Flags a `min-width` or `max-width` media query whose px width is not in `[breakpoints]`. A `max-width` may also be one below a breakpoint.

## Why it matters

Ad-hoc widths scatter layout changes across values the design never named.

## Remedy

Use a declared breakpoint or add the width to `[breakpoints]`.

## Examples

### An undeclared width fires

```css expect=fire file=styles/base/app.css config=breakpoints
@media (min-width: 850px) {
  .a {
    display: block;
  }
}
```

### A declared width is clean

```css expect=clean file=styles/base/app.css config=breakpoints
@media (min-width: 768px) {
  .a {
    display: block;
  }
}
```
