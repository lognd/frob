# ORG005 ungoverned-stylesheet

Every `.css` file of the project is under `css_root` or ignored on purpose. Each block is one source file in a project whose `crunk.toml` is the default preset.

## What it does

Flags a `.css` file outside `css_root` that no `[org] ignore` glob covers; no other rule judges it.

## Why it matters

A stylesheet outside the managed root escapes every palette, scale and organization rule without anyone deciding that.

## Remedy

Move it under `css_root`, or add it to `[org] ignore`.

## Examples

### A sheet outside css_root fires

```css expect=fire file=other/app.css
.card {
  display: block;
}
```

### A sheet under css_root is clean

```css expect=clean file=styles/base/app.css
.card {
  display: block;
}
```
