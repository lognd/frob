# ORG005 ungoverned-stylesheet

Every stylesheet of the project is under `css_root`. Each block is one source file in a project whose
`crunk.toml` is the default preset (`css_root = "styles"`).

## What it does

Flags a `.css` file under the project root but outside `css_root` that no `[org] ignore` glob covers.
Generated and vendored directories (`node_modules`, `dist`, `build`, `vendor` and the like) are never
scanned.

## Why it matters

A stylesheet outside the managed root is invisible to every other rule: whatever it declares is
unchecked, and it ships anyway.

## Remedy

Move the file under `css_root`, or add a glob that matches it to `[org] ignore` to say it is
deliberately ungoverned.

## Examples

### A stylesheet outside css_root fires

```css expect=fire file=legacy/old.css
.old {
  margin: 0;
}
```

### A stylesheet in a bucket is clean

```css expect=clean file=styles/base/reset.css
body {
  margin: 0;
}
```
