# TW004 tailwind-default-color

A colour utility must resolve to the project theme, not Tailwind's built-in palette. Each block is one source file in a default-preset project.

## What it does

Flags `bg-black/10`, `text-red-500` and the like when the colour word is one of Tailwind's v3 default colours and the theme does not define it. The message names the nearest palette token. `transparent` is exempt.

## Why it matters

The utility paints a colour the design never chose.

## Remedy

Use a utility for a palette token, or define the colour in the theme.

## Examples

### A default colour fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="text-red-500" />;
```

### A default colour with an alpha modifier fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="bg-black/10" />;
```

### A theme colour is clean

```tsx expect=clean file=src/a.tsx config=theme-brand
export const A = () => <div className="bg-brand" />;
```
