# TW004 tailwind-arbitrary-property

Arbitrary properties must not hard-code a length or a colour.

## What it does

Flags an arbitrary property utility such as `[width:13px]` or `[color:#fff]` whose whole value is a length or colour literal.

## Why it matters

An arbitrary property sidesteps every scale and palette check.

## Remedy

Use a scale or palette utility, or a token reference.

## Examples

### A hard-coded length property fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="[width:13px]" />;
```

### A var reference is clean

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="[width:var(--w)]" />;
```
