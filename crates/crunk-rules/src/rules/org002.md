# ORG002 class-case

Class names use the configured casing. Each block is one source file in a project whose `crunk.toml`
is the default preset (`class_case = "kebab"`).

## What it does

Flags a class selector that is not written in `[org] class_case` (`kebab`, `snake` or `camel`). A
BEM name is judged part by part: block, element and modifier are each checked, and the `__` and `--`
separators are not case content.

## Why it matters

A stylesheet with two casings cannot be searched, and a component renamed in one casing silently
stops matching its markup written in the other.

## Remedy

Rename the class to the configured casing (and its uses), or change `[org] class_case`.

## Examples

### A snake_case class under kebab fires

```css expect=fire file=styles/components/card.css
.Card_Title {
  margin: 0;
}
```

### A camelCase block in a BEM name fires

```css expect=fire file=styles/components/card.css
.card__titleText {
  margin: 0;
}
```

### Kebab and BEM names are clean

```css expect=clean file=styles/components/card.css
.card {
  margin: 0;
}
.card__title-text {
  margin: 0;
}
.card--is-active {
  margin: 0;
}
```
