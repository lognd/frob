# ORG002 class-case

Class names are written in the casing `[org] class_case` requires. Each block is one source file in a project whose `crunk.toml` is the default preset. The preset requires kebab case.

## What it does

Flags a class selector whose name is not lowercase words joined by the configured separator (kebab `a-b`, snake `a_b`, camel `aB`). The tokens file and `[org] ignore` files are skipped.

## Why it matters

Mixed casing makes class names unguessable and breaks search and rename tooling.

## Remedy

Rename the class to the configured case.

## Examples

### A snake-and-capital class under kebab fires

```css expect=fire file=styles/base/app.css
.Card_Title {
  display: block;
}
```

### A kebab class is clean

```css expect=clean file=styles/base/app.css
.card-title {
  display: block;
}
```
