# ORG001 stylesheet-outside-buckets

Every stylesheet under `css_root` belongs to a declared bucket directory. Each block is one source file in a project whose `crunk.toml` is the default preset. `css_root` is `styles` and the buckets are `base`, `components`, `layouts` and `utilities`.

## What it does

Flags a stylesheet under `css_root` whose first directory is not an `[org] buckets` entry and that no `[org] entry` glob names. Skipped under `model = "utility-first"` and for files `[org] ignore` covers.

## Why it matters

A file in no bucket has no stated role, so nobody knows where its rules belong or in what order they load.

## Remedy

Move the file into a bucket directory, list it under `[org] entry`, or ignore it.

## Examples

### A sheet directly under css_root fires

```css expect=fire file=styles/app.css
.card {
  display: block;
}
```

### A sheet in a bucket is clean

```css expect=clean file=styles/base/app.css
.card {
  display: block;
}
```
