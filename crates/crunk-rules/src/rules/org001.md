# ORG001 stylesheet-outside-buckets

Every stylesheet under `css_root` lives in a declared bucket. Each block is one source file in a
project whose `crunk.toml` is the default preset (buckets base, components, layouts, utilities).

## What it does

Flags a `.css` file under `css_root` that is in no `[org] buckets` directory and is not the tokens
file or an `[org] entry` sheet. Silent when `[org] model` is `utility-first`: that model has no
bucket placement to enforce, and the rule is then inapplicable and reported. Organisation findings
describe the file, so a `crunk:waive` cannot silence them.

## Why it matters

A stylesheet in no bucket has no rule about what it may contain, so it becomes the place where
everything that fits nowhere else piles up.

## Remedy

Move the file into the bucket that matches its role, or declare the bucket in `[org] buckets`.

## Examples

### A sheet in an undeclared directory fires

```css expect=fire file=styles/misc/stray.css
.note {
  margin: 0;
}
```

### A sheet directly under css_root fires

```css expect=fire file=styles/loose.css
.note {
  margin: 0;
}
```

### A sheet in a declared bucket is clean

```css expect=clean file=styles/layouts/stack.css
.stack {
  margin: 0;
}
```
