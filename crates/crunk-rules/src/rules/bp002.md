# BP002 responsive-without-base

A responsive utility of a layout-critical family needs an unprefixed base. These blocks run in a project declaring `[breakpoints]`.

## What it does

Flags a utility with a breakpoint variant (a declared name such as `md:`, or `min-[900px]:`) in a `base_required` family (`md:flex`, `md:w-1/2`) when the same className has no unprefixed utility of that family. `flex`, `grid`, `block` and `hidden` count as one display family.

## Why it matters

Without a base the smallest viewport gets the browser default, not a designed layout.

## Remedy

Add the unprefixed utility for the smallest viewport.

## Examples

### A prefixed flex with no base fires

```tsx expect=fire file=src/a.tsx config=breakpoints
export const A = () => <div className="md:flex" />;
```

### A base plus override is clean

```tsx expect=clean file=src/a.tsx config=breakpoints
export const A = () => <div className="hidden md:flex" />;
```
