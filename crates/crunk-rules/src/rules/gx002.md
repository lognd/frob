# GX002 focus-unreachable

Every focusable control can be reached with the pad.

## What it does

Builds the focus graph of each scene document (focusable controls, document-order neighbours inside focus groups, `data-nav-*` overrides) and fires for each control no sequence of moves reaches from the default selection. The finding names the control and the line.

## Why it matters

A control the pad cannot reach is unusable on a console, with no mouse to fall back on.

## Remedy

Add a `data-nav-*` move to it from a neighbour, or let document order reach it by putting it inside a focus group.

## Examples

### Fires

```html expect=fire file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default data-nav-down="none"></button>
<button data-id="options"></button>
```

### Clean

```html expect=clean file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default></button>
<button data-id="options"></button>
```
