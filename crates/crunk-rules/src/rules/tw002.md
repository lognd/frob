# TW002 tailwind-theme-unknown-token

A Tailwind theme entry may only point at a token the export defines. These blocks run in a project whose `[tailwind]` config is ingested.

## What it does

Flags a Tailwind theme entry whose value is exactly `var(--x)` when `--x` is not one of the tokens `crunk tokens` exports. Literal values such as `#282828` are not judged.

## Why it matters

The utility would resolve to a custom property nothing defines, so the style silently drops out.

## Remedy

Point the entry at an exported token, or declare the missing token in `crunk.toml`.

## Examples

### An entry mapped to an unexported token fires

```tsx expect=fire file=src/a.tsx config=theme-unknown
export const A = () => <div className="p-4" />;
```

### An entry mapped to an exported token is clean

```tsx expect=clean file=src/a.tsx config=theme-brand
export const A = () => <div className="p-4" />;
```
