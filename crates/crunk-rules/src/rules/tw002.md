# TW002 tailwind-arbitrary-color-off-palette

Arbitrary Tailwind colours must be palette colours.

## What it does

Flags a colour utility with an arbitrary colour (`bg-[#123456]`) that is not within `[lint] color_tolerance` of a palette colour in any mode.

## Why it matters

A literal colour in a class bypasses the palette, so themes and contrast checks cannot see it.

## Remedy

Use a palette colour utility or add the colour to the palette.

## Examples

### An off-palette colour fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="bg-[#123457]" />;
```

### A utility with no arbitrary colour is clean

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="flex" />;
```
