# TW001 arbitrary-value-off-design

An arbitrary Tailwind value must still sit on the design law. Each block is one source file in a
project whose `crunk.toml` is the default preset. The examples run against a stand-in for the
project's Tailwind (the real one needs node and an install), which compiles the shapes shown.

## What it does

Judges an arbitrary-value utility (`p-[13px]`, `bg-[#282828]`, `z-[99]`) on the CSS Tailwind itself
compiles it to, not on the class name: a `z-index` against the declared layers (only when layers are
declared), a colour against the palette, and a length of a governed family (`p`, `m`, `gap`,
`inset`, `rounded`, `text`, `w`, `h`, `min-w`, `min-h`, `max-h`) against its scale; a length in a
unit that cannot be compared with px (`dvh`, `%`) is off the scale by construction. `max-w` is
exempt. A utility Tailwind could not answer for (no node, no install, static mode) is Unresolved,
never clean; one Tailwind reports as not Tailwind syntax has no CSS and is exempt.

## Why it matters

`p-[13px]` is the one-off that SPACE001 would catch in a stylesheet, written where the stylesheet
rules do not look.

## Remedy

Use the scale utility, or add the value to the design law.

## Examples

### An off-scale padding fires

```tsx expect=fire file=src/Card.tsx
export const Card = () => <div className="p-[13px]" />;
```

### An off-palette colour fires

```tsx expect=fire file=src/Card.tsx
export const Card = () => <div className="bg-[#123456]" />;
```

### An undeclared z-index fires

```tsx expect=fire file=src/Card.tsx
export const Card = () => <div className="z-[99]" />;
```

### A viewport unit on a governed family fires

```tsx expect=fire file=src/Card.tsx
export const Card = () => <div className="max-h-[32dvh]" />;
```

### Values on the scale, the palette and the layers are clean

```tsx expect=clean file=src/Card.tsx
export const Card = () => <div className="p-[12px] bg-[#2f6fed] z-[100]" />;
```

### Utilities Tailwind does not know are exempt

```tsx expect=clean file=src/Card.tsx
export const Card = () => <div className="frobnicate-[13px]" />;
```
