# TW001 tailwind-arbitrary-off-scale

Arbitrary Tailwind lengths must be steps of the scale they belong to. Each block is one source file in a project whose `crunk.toml` is the default preset.

## What it does

Flags an arbitrary-value utility such as `p-[13px]` whose length is not a step of the `[scales]` list its root takes (spacing, font sizes, radii, sizes). `rem` and `em` lengths are converted with the root font size; values using `var()` or `calc()` are not judged.

## Why it matters

An off-scale length is a one-off that drifts from the design and cannot be changed in one place.

## Remedy

Use a scale utility, or add the step to `[scales]` if the design needs it.

## Examples

### An off-scale padding fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="p-[13px]" />;
```

### An on-scale value is clean here

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="p-4" />;
```
