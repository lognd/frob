# TW001 tailwind-arbitrary-off-scale

Arbitrary Tailwind values must come from the design. Each block is one source file in a project whose `crunk.toml` is the default preset.

## What it does

Flags an arbitrary-value utility whose value is off its governed scale: a colour (`bg-[#2f6eec]`) that is not a palette colour, a z-index (`z-[999]`) that is not a declared layer, or a px/rem length (`p-[13px]`) that is not a step of the `[scales]` list its prefix takes. A length in another unit (`max-h-[32dvh]`) in a governed family cannot be compared and is flagged too. `max-w`, `opacity` and the like are exempt. The message names the nearest token.

## Why it matters

An off-scale value is a one-off that drifts from the design and cannot be changed in one place.

## Remedy

Use the scale utility or token the message names, or add the step to `[scales]`, `[palette]` or `[layers]` if the design needs it.

## Examples

### An off-scale padding fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="p-[13px]" />;
```

### An off-palette colour fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="bg-[#123456]" />;
```

### An undeclared z-index fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="z-[999]" />;
```

### A named scale utility is clean here

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="p-4" />;
```
