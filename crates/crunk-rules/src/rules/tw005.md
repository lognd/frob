# TW005 tailwind-default-scale

A named utility must come from the declared scale, not Tailwind's default one. Each block is one source file in a default-preset project.

## What it does

Flags `p-5`, `h-9` and the like when the key is in Tailwind's default table for that family (spacing, borderRadius, fontSize, zIndex, ...) and the theme does not define it. `z-` utilities are judged only when `[layers]` is declared; keyword values (`h-full`, `text-lg`) are not.

## Why it matters

The utility silently falls through to a built-in step that is not part of the design.

## Remedy

Define the key in the theme, or use a utility from the declared scale.

## Examples

### A default spacing key fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="p-5" />;
```

### A keyword value is clean

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="h-full" />;
```
