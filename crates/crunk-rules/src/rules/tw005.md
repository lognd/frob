# TW005 tailwind-dynamic-class

Class names must be statically visible.

## What it does

Flags a `className` site with a part built at runtime, such as a template literal interpolation.

## Why it matters

Tailwind only generates classes it can see in the source, and crunk cannot judge a class it cannot read.

## Remedy

Spell out the full class names and choose between them.

## Examples

### An interpolated class fires

```tsx expect=fire file=src/a.tsx
export const A = (p: { n: string }) => <div className={`p-${p.n}`} />;
```

### A static class is clean

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="p-4" />;
```
