# TW005 tailwind-default-scale

A scale utility must come from the declared scales, not Tailwind's defaults. Each block is one source
file in a project whose `crunk.toml` is the default preset (spacing 0, 4, 8, 12, ...); the examples
run against a stand-in for the project's Tailwind.

## What it does

Flags a non-arbitrary utility whose key is in Tailwind's default key table for its family (`p-5`,
`rounded-lg`, `z-10`) when the theme does not override that key, unless the value Tailwind compiles
it to is already on the declared scale (`p-0` is `0px`; `p-3` is 12px, a declared step). Families:
spacing (`p`, `m`, `gap`, `inset`, `w`, `h`, `min-w`, `min-h`, `max-h`), `rounded`, numeric `text-`
keys, and `z` / `-z` when layers are declared. Arbitrary utilities are TW001's. A utility Tailwind
could not answer for is Unresolved.

## Why it matters

The default scale is a second design system running next to yours; a `p-5` is a 20px padding that
no token ever declared.

## Remedy

Use a utility whose key the theme defines (a namespaced token key), or add the step to the scale.

## Examples

### A default spacing key off the declared scale fires

```tsx expect=fire file=src/Card.tsx
export const Card = () => <div className="p-5" />;
```

### A default radius key fires

```tsx expect=fire file=src/Card.tsx
export const Card = () => <div className="rounded-lg" />;
```

### A default key whose value is on the declared scale is clean

```tsx expect=clean file=src/Card.tsx
export const Card = () => <div className="p-0 p-3" />;
```

### A key outside the default table is clean

```tsx expect=clean file=src/Card.tsx
export const Card = () => <div className="p-brand" />;
```
