# TW003 alpha-modifier-without-placeholder

An alpha modifier needs a theme colour that can take alpha. Each block is one source file in a
project whose `crunk.toml` is the default preset plus `[tailwind] config`; the examples run against
a stand-in theme where `brand` is a literal colour or an `<alpha-value>` mapping.

## What it does

Flags a utility like `bg-brand/50` when the theme entry `brand` maps to text without an
`<alpha-value>` placeholder: Tailwind drops the modifier silently. A utility whose key is not in the
theme is skipped. Warn by default.

## Why it matters

The class reads as 50% opaque and renders fully opaque, and nothing complains.

## Remedy

Emit the colour as `rgb(var(--x-rgb) / <alpha-value>)` (`[tailwind] alpha_channels = true`).

## Examples

### An alpha modifier over a plain colour fires

```tsx expect=fire config=tw-theme-plain file=src/Card.tsx
export const Card = () => <div className="bg-brand/50" />;
```

### An alpha-capable entry is clean

```tsx expect=clean config=tw-theme-alpha file=src/Card.tsx
export const Card = () => <div className="bg-brand/50" />;
```

### No modifier is clean

```tsx expect=clean config=tw-theme-plain file=src/Card.tsx
export const Card = () => <div className="bg-brand" />;
```
