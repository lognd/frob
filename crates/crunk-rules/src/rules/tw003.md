# TW003 tailwind-arbitrary-on-scale

An arbitrary length that equals a scale step should be written as the scale utility.

## What it does

Flags an arbitrary-value utility such as `p-[16px]` whose length is a step of its scale, so a named utility exists.

## Why it matters

The arbitrary form hides that the value is a scale step and does not follow later scale changes.

## Remedy

Replace it with the scale utility.

## Examples

### An on-scale arbitrary value fires

```tsx expect=fire file=src/a.tsx
export const A = () => <div className="p-[16px]" />;
```

### A named utility is clean

```tsx expect=clean file=src/a.tsx
export const A = () => <div className="p-4" />;
```
