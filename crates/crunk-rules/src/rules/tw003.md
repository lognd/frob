# TW003 tailwind-alpha-no-placeholder

An alpha modifier needs a theme value that can take alpha. These blocks run in a project whose `[tailwind]` config is ingested (Tailwind v3).

## What it does

Warns on a utility such as `bg-brand/50` when the theme entry `brand` maps to a value without an `<alpha-value>` placeholder, so the `/50` is a silent no-op.

## Why it matters

The modifier looks like it fades the colour but changes nothing.

## Remedy

Map the entry to `rgb(var(--x-rgb) / <alpha-value>)` (`alpha_channels = true` in `[tailwind]`), or drop the modifier.

## Examples

### An alpha modifier on a plain var fires

```tsx expect=fire file=src/a.tsx config=theme-brand
export const A = () => <div className="bg-brand/50" />;
```

### An alpha modifier on a placeholder mapping is clean

```tsx expect=clean file=src/a.tsx config=theme-alpha
export const A = () => <div className="bg-brand/50" />;
```
