# ORG003 component-prefix

A class in a `components` sheet carries the component's name. Each block is one source file in a project whose `crunk.toml` is the default preset. The component is the sheet's file stem and the preset sets `component_prefix = true`.

## What it does

Flags a class selector in `styles/components/<name>.css` whose name, ignoring case and separators, does not start with `<name>`. Off when `component_prefix = false`.

## Why it matters

A prefixed class cannot collide with another component's and says which file owns it.

## Remedy

Rename the class to start with the component name, or move it to a shared bucket.

## Examples

### A class without the prefix fires

```css expect=fire file=styles/components/card.css
.title {
  display: block;
}
```

### A prefixed class is clean

```css expect=clean file=styles/components/card.css
.card-title {
  display: block;
}
```
