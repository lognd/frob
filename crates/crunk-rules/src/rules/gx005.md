# GX005 focus-nav-invalid

Focus attributes name things that exist.

## What it does

Fires for a `data-nav-up|down|left|right` that names a `data-id` no element has or an element that is not an enabled focusable, a `data-focus-wrap` other than `wrap` or `clamp`, and a `data-focus-axis` other than `vertical` or `horizontal`. `none` blocks a direction and is valid.

## Why it matters

A dangling move is silently ignored by the engine, so the graph the author drew is not the one that ships.

## Remedy

Correct the target or the value, or use `none` to block a direction on purpose.

## Examples

### Fires

```html expect=fire file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default data-nav-down="ghost"></button>
<button data-id="options"></button>
```

### Clean

```html expect=clean file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default data-nav-down="options"></button>
<button data-id="options"></button>
```
