# GX004 focus-default

A scene selects exactly one control when it opens.

## What it does

Fires when a scene with focusable controls marks no `data-focus-default`, when it marks a second one, and when the mark sits on an element that is not focusable or is disabled. The finding names the element and the line.

## Why it matters

Without a declared default the engine picks whatever comes first, and two defaults make the start order-dependent.

## Remedy

Mark exactly one enabled control with `data-focus-default`.

## Examples

### Fires

```html expect=fire file=design/scenes/menu.scene.html
<button data-id="play"></button>
<button data-id="options"></button>
```

### Clean

```html expect=clean file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default></button>
<button data-id="options"></button>
```
