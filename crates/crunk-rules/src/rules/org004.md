# ORG004 custom-property-outside-tokens

Custom properties are defined in the generated tokens file only. Each block is one source file in a
project whose `crunk.toml` is the default preset (`tokens_only_custom_props = true`).

## What it does

Flags a `--name:` definition in any stylesheet other than the tokens file. A `var()` use is not a
definition and is never flagged. With `[org] tokens_only_custom_props = false` the rule is
inapplicable and the skip is reported.

## Why it matters

A custom property defined next to its use is a token that the token file does not know: it escapes
the scales, the modes and the generated export.

## Remedy

Add the value to the design law so it is generated into the tokens file, or use a literal that is on
the scale.

## Examples

### A custom property in a component sheet fires

```css expect=fire file=styles/components/card.css
.card {
  --card-gap: 12px;
}
```

### A var() use is clean

```css expect=clean file=styles/components/card.css
.card {
  margin: var(--space-12);
}
```
