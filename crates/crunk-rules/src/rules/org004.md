# ORG004 custom-prop-outside-tokens

Custom properties are defined only in the generated tokens file. Each block is one source file in a project whose `crunk.toml` is the default preset. The preset sets `tokens_only_custom_props = true`.

## What it does

Flags a `--x:` definition in any stylesheet other than the tokens file. Off when `tokens_only_custom_props = false`.

## Why it matters

Values defined next to their use bypass the token table, so the design spec stops being the one source of truth.

## Remedy

Declare the value in `crunk.toml` so the tokens file exports it, then use `var()`.

## Examples

### A definition in a bucket sheet fires

```css expect=fire file=styles/base/app.css
:root {
  --brand: #1a1a1a;
}
```

### A rule without definitions is clean

```css expect=clean file=styles/base/app.css
.card {
  color: var(--color-ink);
}
```
