# BP003 max-width-media-query

Styles are mobile-first. These blocks run in a project declaring `[breakpoints]`.

## What it does

Flags a `max-width` media query.

## Why it matters

Desktop-first queries undo styles instead of layering them and fight the `min-width` utilities.

## Remedy

Write the base style for small screens and layer up with `min-width`.

## Examples

### A max-width query fires

```css expect=fire file=styles/base/app.css config=breakpoints
@media (max-width: 768px) {
  .a {
    display: block;
  }
}
```

### A min-width query is clean

```css expect=clean file=styles/base/app.css config=breakpoints
@media (min-width: 768px) {
  .a {
    display: block;
  }
}
```
