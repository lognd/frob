# BP003 fixed-width-exceeds-mobile

A fixed width must fit the smallest viewport. These blocks run in a project declaring `[breakpoints]` with smallest sm=640.

## What it does

Flags a `width` or `min-width` declaration in px or rem wider than the smallest declared breakpoint. `max-width`, percentages and other units are not judged.

## Why it matters

A fixed width wider than the smallest breakpoint overflows every viewport below it.

## Remedy

Use a fluid width (`%`, `max-width`), or set the fixed width inside a `min-width` media query.

## Examples

### A wide fixed width fires

```css expect=fire file=styles/base/app.css config=breakpoints
.a {
  width: 900px;
}
```

### A narrow width is clean

```css expect=clean file=styles/base/app.css config=breakpoints
.a {
  width: 320px;
}
```
