# GX003 focus-trap

The pad can always leave a control it has moved onto.

## What it does

Fires for each control the pad can reach from the default selection but from which no sequence of moves returns to it. The finding names the control and the line.

## Why it matters

A trap strands the player on a control with no way out except quitting.

## Remedy

Add a `data-nav-*` move out of the control, or make its group wrap.

## Examples

### Fires

```html expect=fire file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default></button>
<button data-id="options" data-nav-up="none"></button>
```

### Clean

```html expect=clean file=design/scenes/menu.scene.html
<button data-id="play" data-focus-default></button>
<button data-id="options"></button>
```
