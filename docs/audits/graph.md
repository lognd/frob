# Audit: `src/frob/graph/**` -- the obligation-graph foundation

North-star under test: *"if `frob check` passes, the code is actually good."*
This audit hunts every way that is FALSE inside the graph layer (the substrate
every gate trusts). Verified with source reads of the whole package plus
`frob.lang` binding/parse paths and gate consumers.

---

## (A) What is implemented, and how (real mechanism, per file)

### `__init__.py` -- build/load/resolve orchestration
- `build_graph(root, cache)`: `connect()` (writable) -> `_load_exclude_globs`
  -> `_walk_source_files` + `_walk_doc_files` (manual `os.walk`, prune excluded
  dirs before descent, T-0239) -> per-file ingest -> `_prune_stale_cache` ->
  `_finalize_build` (set root, single `conn.commit()`, `load_all`). One
  transaction for the whole build; commit only at the end.
- Incrementality: `_process_source_file` computes `_content_hash` (sha256 of
  bytes) and compares to cached `files.content_hash`; equal -> `load_file_data`
  (cache hit, no reparse); differ -> `_parse_source_file_fresh` (`parse_file`,
  `_dedupe_symbols`, `parse_directives`, `store_file_data`).
- `_dedupe_symbols`: last-def-wins by `symref` (overload/redef tolerance,
  T-0024).
- `load_graph(cache)`: read-only (`connect_readonly`, `mode=ro`). Returns
  `CacheCorrupt` (missing/unreadable/never-built), `CacheStale` (any cached
  file's on-disk hash moved via `_first_stale_cached_file`), else `Ok`.
- `resolve(snapshot, ref)`: exact `path::qualname` key hit, else unique
  `qualname == ref or qualname.endswith(".ref")` match; >1 -> `AmbiguousSymbol`,
  0 -> `UnknownSymbol`.
- `edges_from/edges_to`: linear scan by exact string equality on `src`/`target`.

### `dsl.py` -- comment-DSL + markdown anchors
- `parse_directives`: flattens every `RawComment` to physical lines, resolves
  each comment's binding src via `_resolve_block_srcs` (backward-propagates a
  resolved `following` through a gap-free line-adjacent run, T-0313),
  `_fold_continuations` joins trailing-backslash runs, `_parse_line` maps
  `frob:<verb> target key="v"` to an `Edge` or `MalformedDirective`.
- `_VERB_TABLE` maps 11 verbs to `EdgeKind`; `_RESERVED_MARKER_VERBS`
  (`secret-fake`) silently skipped; unknown verb -> malformed.
- `_parse_attrs`: `key="value"` regex, strips a trailing `#...` noqa tail
  (T-0309), enforces `waive` needs `reason`, `tests` `kind in {unit,integration,e2e}`.
- `markdown_anchors`: per-line heading tracking -> GitHub slug (`slugify` +
  `dedupe_slug`), `<!-- frob:describes symref [facet] -->` -> DESCRIBES edge
  `src=doc#slug`, `target=symref`, `attrs.facet`.

### `digest.py` -- three sha256 facets
- `sig`/`body`/`doc` over `RawSymbol.sig_tokens`/`body_tokens`/`doc_text`,
  token tuples joined by NUL. `body` empty for class/const/type.

### `cache.py` -- sqlite `.frob/cache.db`
- `connect`: WAL, busy_timeout 30s, schema-version wipe-on-mismatch,
  `_check_fingerprint` (frob + tree-sitter package versions -> delete all
  derived rows + `root` on mismatch, T-0243), corruption -> delete-and-recreate.
- `connect_readonly`: `mode=ro` + `query_only`, cannot take write lock (T-0232).
- `store_file_data`: per-file delete-then-insert of symbols/edges/malformed +
  upsert `files` row. `load_all`: rebuild whole `GraphSnapshot` from rows.

### `callgraph.py` -- best-effort private-callee call graph
- `_called_names`: identifier-followed-by-`(` token scan. `build_call_graph`:
  records edges to PRIVATE (`_`-prefixed) callees only; `closure`: depth+node
  capped BFS. Explicitly documented as unsound triage aid.

### `lock.py` -- ack + drift
- `acknowledge`: ref must be an edge endpoint AND resolve; records
  `_facet_for_ref` (first DESCRIBES facet, else `sig`) digest. `drift`: pure
  `_stale_items` (digest moved) + `_dangling_edges` (endpoint with `::` gone,
  with rename candidates). `write_lock`: atomic mkstemp+`os.replace`.

### `_generated.py`
- `is_generated_source`: regex over first 20 lines (`@generated`, `do not
  edit`, `generated by`), read failure -> False.

## (B) FALSE-NEGATIVE / EVASION findings (priority)

See numbered defects in (E). The load-time false negatives (G1, G2) and the
bare-target dangling hole (G3) are the ones that most directly break the
north-star.

## (C) FALSE-POSITIVE / soundness

Graph is mostly conservative (errs toward "still owes"). The real
false-positive risk is mis-binding (G4/G8): a directive silently binding to the
wrong or a fallback symbol, which can *waive the wrong rule* or make a doc edge
count for the wrong symbol.

## (D) Per-component verdict (pessimistic: right way or fast way?)

| Component | Verdict |
|---|---|
| `build_graph` incremental cache | RIGHT-ish, but `load_graph` staleness is the FAST way -- it never detects **added** files (G1). |
| content-hash freshness | FAST. Hash-then-reparse double-read is a TOCTOU window (self-heals next build) (G7). |
| `dsl.parse_directives` binding | Mostly RIGHT for Python; heuristic 2-line window + backprop is FAST and mis-binds at boundaries (G4). |
| `markdown_anchors` | RIGHT for slugs; but describes-target existence never checked (G3). |
| `digest` facets | RIGHT for tokens; body-empty-for-class + comment-invisibility are silent-no-drift blind spots (G5). |
| `cache` fingerprint | RIGHT idea, FAST list -- hardcoded `_FINGERPRINT_PACKAGES`; new grammar => stale served (G6). |
| `_process_doc_file` decode | WRONG -- crashes whole build on a non-UTF-8 `.md` (G2). |
| `lang._parse` partial-tree | FAST -- a syntactically broken file with >0 children is treated as clean (G9). |
| `resolve` suffix match | FAST -- ambiguous/loose; documented but can mis-resolve bare refs (G10). |
| `acknowledge` facet pick | FAST -- only ever acks ONE facet per ref (G11). |
| `callgraph` | Honestly labeled best-effort; fine for triage, unsound by design. |

## (E) Concrete gaps / defects

### G1 -- HIGH: `load_graph` never detects an ADDED file; returns `Ok` on a stale-incomplete snapshot
`__init__.py:374-435` (`_first_stale_cached_file` / `load_graph`). The staleness
check only iterates rows already in `files`:
```
for path, stored_hash in conn.execute("SELECT path, content_hash FROM files"):
```
A brand-new source/doc file on disk has no cache row, so nothing is compared,
`stale_path is None`, and `load_graph` returns `Ok(snapshot)` **missing that
file's symbols, edges, malformed directives and doc obligations entirely.**
Docstring claims "`Err(CacheStale)` if any on-disk hash moved" -- true, but
"added" is drift too and is silently accepted.
- Repro: build once. `git add` a new module `src/frob/new.py` containing a
  malformed directive (`# frob:bogus x`) and an undocumented public function.
  Any command that reads via `load_graph` without forcing a rebuild
  (`dup_runner`, `sys_runner`, `release_runner`, `ack_runner`, `_prework` when
  load returns Ok) uses the stale snapshot -> the malformed directive and
  COV001 obligation are invisible until something else forces `build_graph`.
- Fix: in `load_graph`, also compare the *set* of on-disk source/doc files
  (reuse `_walk_source_files`/`_walk_doc_files`) against `files` rows; any path
  present on disk but absent from cache -> `CacheStale`. (Cost is one walk,
  which is already paid on build.)

### G2 -- HIGH: non-UTF-8 markdown crashes the entire build (uncaught `UnicodeDecodeError`)
`__init__.py:249-253` (`_process_doc_file`):
```
try:
    text = path.read_text(encoding="utf-8")
except OSError as exc:
    ...
```
`UnicodeDecodeError` subclasses `ValueError`, **not** `OSError` (verified). A
single latin-1/UTF-16 `.md` file under `docs/` raises past this handler,
`build_graph`'s `finally` closes the conn *without committing* (whole build
rolled back), and the exception propagates uncaught out of `build_graph` --
which its callers treat as a `Result`, so `frob check` hard-crashes rather than
returning a violation. One committed mojibake doc = repo-wide check outage.
- Repro: `printf '\xff\xfeheading\n' > docs/bad.md; frob check` -> traceback.
- Fix: catch `(OSError, UnicodeDecodeError)` (or read with
  `errors="replace"` like `_crawl_reachable` at line 3330 already does) and
  skip-with-warning, matching the source-file degrade path.

### G3 -- MEDIUM: a `frob:describes`/directive edge with a BARE (no `::`) target is never dangling-checked
`lock.py:120-126` (`_vanished_endpoint`): only endpoints containing `"::"` are
considered:
```
if "::" in edge.target and edge.target not in snapshot.symbols: ...
```
A doc anchor written as an HTML comment with verb `describes` and a bare
name like `my_func` (which `_DESCRIBES_RE` happily accepts as
`symref=my_func`) produces an edge whose target has no `::`, so it can
point at a **nonexistent symbol** and never surface as DRIFT002 dangling.
The doc silently "describes" nothing.
- Repro: add such a comment naming a nonexistent symbol under a heading in
  a linked doc; build + drift -> zero dangling reported.
- Fix: resolve bare describes targets through `resolve()` at edge-build or
  drift time; a bare target that neither resolves nor is a known non-symbol
  namespace (ticket/invariant ids handled elsewhere) is dangling.

### G4 -- MEDIUM: directive binds to a FALLBACK symbol when the def is >2 lines below (silent mis-bind)
`lang/_common.py:249-255` (`_find_following_symbol`) uses a fixed window
`end < sym.span[0] <= end + 2`. `dsl._enclosing_src`/`_resolve_block_srcs` then
fall back to `enclosing` (often module -> bare `path`) when `following` is None.
Two blank lines (or a blank line + a decorator whose node start is offset)
between a directive block and its def drop the def out of the window, so the
directive binds to the enclosing scope instead of the intended symbol.
- Consequence: `# frob:waive RULEXXX reason="..."` bound to the wrong (broader)
  src can waive a rule for a symbol the author never intended, or a
  `frob:doc`/`frob:tests` edge lands on the file/module rather than the
  function (function then still reads as undocumented -> confusing COV001, or
  the waive silently over-applies).
- Repro: place `# frob:waive ARCH001 reason="x"` then two blank lines then the
  offending `def`; the waive binds to the module path, not the def.
- Fix: this is a `frob.lang` window constant, but graph is the consumer that
  trusts it -- either widen/annotate intent, or have `parse_directives` emit a
  `MalformedDirective` when a directive resolves only to a bare `path` src
  (no enclosing/following symbol) for verbs that semantically require a symbol
  (waive/doc/tests/invariant).

### G5 -- MEDIUM: real changes that leave all three digests unchanged (false "no drift")
`digest.py:35-37`: `body` is empty for class/const/type; and body/sig tokens are
leaf-token streams that exclude comments. Concrete no-drift cases:
- Editing an **inline comment that states an invariant** inside a function body
  changes no token -> `body` digest identical -> an acked `frob:invariant`
  never goes stale even though the stated contract text changed.
- Changing a **class-level statement** (e.g. a class attribute default or a
  `if TYPE_CHECKING` branch) when that statement is not itself a tracked
  symbol: class `body` digest is empty by design, so the class's digest does
  not move.
- Repro: ack a class's `body` facet; add a class attribute; drift reports
  nothing.
- Fix: document the facet's true coverage in `graph.md` (partly done) AND
  either fold class-body member-set into `sig`, or reject `body`-facet acks on
  class/const/type symbols (their body digest is a constant, so a `body` ack is
  meaningless and can never detect drift).

### G6 -- MEDIUM: `_FINGERPRINT_PACKAGES` is a hardcoded allowlist; a new grammar serves a stale cache
`cache.py:42-48`. The comment says "Extend this tuple whenever a new grammar
package is added to `frob.lang`" -- a manual coupling with no static check.
`frob.lang` supporting a new language via a package not in this tuple means an
upgrade that changes that language's parse output serves cached (wrong)
symbols/edges under an unchanged fingerprint -- exactly the T-0243 incident the
mechanism was built to prevent, reintroduced for the new language.
- Repro: add a grammar package, bump its version, rebuild -> old symbols for
  files in that language persist.
- Fix: derive the fingerprint package list from `frob.lang`'s actual grammar
  registry (single source of truth) instead of a hand-copied tuple, or add a
  gate/test asserting every `supported_extensions` grammar package is in the
  fingerprint set.

### G7 -- LOW: hash/parse double-read TOCTOU stores new content under old hash
`__init__.py:274` computes `_content_hash(path)` (read #1), then
`_parse_source_file_fresh` -> `parse_file` re-reads bytes (read #2 in
`lang/_parse`). A write between the two stores read-#2 symbols under read-#1's
hash. Self-heals (next build sees a hash mismatch), and `load_graph` would flag
it stale, so blast radius is one transient snapshot. Still a correctness nit:
during that window the cached hash does not describe the cached symbols.
- Fix: hash the exact bytes `parse_file` parsed (return the digest from the
  parse), rather than hashing separately before parsing.

### G8 -- LOW: `_resolve_block_srcs` backprop can carry a `following` binding across an unrelated stacked comment
`dsl.py:297-341`. Propagation fills any unresolved comment in a gap-free
line-adjacent run with the nearest resolved `following` below it. A block of
mixed content (a plain explanatory comment stacked directly above a directive
that resolves to a def) will push the def binding up onto the plain comment's
line too. Harmless when the plain comment carries no `frob:` directive, but if a
`frob:` directive sits in that run intending the *enclosing* scope, it is
silently rebound to the following def.
- Repro: contiguous run: `# frob:ticket T-1` (meant for module) immediately
  above `# frob:doc docs/x.md` immediately above `def f` -> the ticket edge
  rebinds to `f` rather than the module.
- Fix: only backprop to comments that themselves contain a `frob:` directive
  whose verb is symbol-scoped, or require an explicit blank-line boundary
  between module-scoped and symbol-scoped directive blocks (documented rule).

### G9 -- MEDIUM: partially-broken source is treated as a clean file (obligations silently vanish)
`lang/__init__.py:179-184`: `_parse` returns `ParseFailed` ONLY when
`has_error and child_count == 0`. A file that is syntactically broken but has
any top-level children returns `Ok` with whatever symbols tree-sitter salvaged.
Symbols after the error region are dropped, and `build_graph` stores that
truncated symbol set as authoritative. Their public-doc/COV, directive, and
digest obligations disappear with no violation.
- Repro: introduce a mid-file syntax error below a public function; that
  function (and its `frob:` directives below the break) drop out of the graph;
  `frob check` reports nothing about them.
- Fix: surface a graph-level violation (or at least a WARN + a `MalformedFile`
  record) when `tree.root_node.has_error` even with children, so a broken file
  is a hard signal rather than a silent obligation loss.

### G10 -- LOW: `resolve` suffix match can silently mis-resolve a bare ref
`__init__.py:445-457`. `ref="foo"` resolves to a unique `X.foo` even if the
author meant a top-level `foo` elsewhere; and two identical qualnames in
different files make even a fully-qualified-by-name ref `AmbiguousSymbol`. For
`acknowledge` (`lock.py:100`) a loose suffix hit records a digest for the wrong
symbol, so drift then tracks the wrong thing.
- Fix: prefer exact-qualname matches over `.endswith` suffix matches, and
  require a `path::` prefix to disambiguate when qualnames collide, rather than
  returning the sole suffix hit.

### G11 -- MEDIUM: `acknowledge` records only ONE facet per ref; extra describes-facet obligations are never lockable
`lock.py:73-78,105-107` (`_facet_for_ref`): returns the facet of the *first*
DESCRIBES edge targeting `ref`. If a symbol is described by two anchors with
different facets (e.g. one `sig`, one `body`/`doc`), `acknowledge` only ever
writes the first facet's entry. The second facet's contract can drift with no
stale-ack signal because it was never acked.
- Repro: two `frob:describes S sig` and `frob:describes S doc` in different
  docs; `frob ack S` -> only the `sig` LockEntry exists; edit S's docstring ->
  no DRIFT001 for the `doc` facet.
- Fix: `acknowledge` should record a LockEntry for *every* distinct facet
  requested by any DESCRIBES edge targeting the ref, not just the first.

### G12 -- LOW: `store_file_data` docstring claims "one commit" but never commits
`cache.py:405`. It performs delete+insert but no `conn.commit()`; the only
commit is in `_finalize_build`. Misleading for anyone reusing `store_file_data`
outside a `build_graph` transaction (they'd lose data on process exit). Doc/code
contract mismatch.
- Fix: reword to "one transaction step (caller commits)".

## Ranked top-5 (fix these first)

1. **G1** (HIGH) -- `load_graph` blind to added files: any load-only command
   silently operates on an incomplete graph, directly breaking the north-star.
2. **G2** (HIGH) -- one non-UTF-8 `.md` crashes the whole `frob check`.
3. **G9** (MED) -- partially-broken source treated as clean; obligations vanish
   with no violation.
4. **G3** (MED) -- bare-target `frob:describes` never dangling-checked; docs can
   describe nonexistent symbols.
5. **G11** (MED) -- multi-facet describes only partly ackable; a whole facet's
   drift is undetectable.

## Notes -- checked and found correct / deliberately skimmed

Verified correct (fixer need not re-check):
- `write_lock` atomicity: mkstemp in target dir + `os.fdopen` + `os.replace`
  with tmp-unlink on any `BaseException` -- sound atomic replace.
- `connect_readonly` truly cannot take the write lock (`mode=ro` +
  `query_only`), so `load_graph` will not serialize behind builders (T-0232).
- Corruption recovery (`_recreate`, `_apply_schema_with_recovery`) handles both
  the non-sqlite-file and corrupt-btree-page cases and unlinks `-wal`/`-shm`.
- Schema-version and fingerprint mismatch both drop the `root` key, so a
  post-invalidation `load_graph` correctly reports `CacheCorrupt` rather than an
  empty `Ok`.
- `_dedupe_symbols` last-def-wins genuinely prevents the symref PRIMARY KEY
  crash on overloads/redefs.
- Deleted-file staleness IS caught (`_content_hash` returns None != stored hash;
  `_prune_stale_cache` cleans rows). Only *additions* are missed (G1).
- `closure` BFS is depth+node bounded and cycle-guarded; off-by-one on
  `max_nodes` checked -- correct (`order[:max_nodes]`).
- `slugify`/`dedupe_slug` GitHub-anchor semantics (T-0212) match the documented
  one-for-one space->hyphen and repeat-suffix rules.
- `_fold_continuations` correctly refuses to fold a following line that is
  itself a fresh `frob:<verb>` directive (T-0286 corruption repro).

Skimmed / out of scope (audit boundary):
- `frob.lang` walkers (`_walk_python/rust/c/typescript/strata`) read only far
  enough to assess directive-binding soundness (G4/G9). Language-specific
  `sig_tokens`/`body_tokens` composition per grammar was NOT exhaustively
  verified -- G5's facet blind spots are argued from the Python case; other
  languages may have additional facet-invisibility cases.
- `frob.gates` consumers were checked only to trace how `load_graph` vs
  `build_graph` is invoked and how describes/doc/dangling edges are consumed
  (to substantiate G1/G3). The gate rule logic itself is a separate audit.
- `callgraph.py` unsoundness is by explicit design (best-effort triage) and is
  not counted as a defect; only noted for completeness.
- Concurrency across multiple simultaneous `build_graph` writers was reasoned
  about (single WAL writer + 30s busy_timeout, whole-build single transaction)
  but not stress-tested; no distinct race defect found beyond the G7 single-file
  TOCTOU.
