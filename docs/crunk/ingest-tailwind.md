# Tailwind ingest

`crunk_ingest::ingest_tailwind` reads the Tailwind theme named by `[tailwind]` in `crunk.toml`
(`config` or `css_entry`) and returns a `TailwindTheme`. Without that section it returns `None`
and spawns nothing.

- Version: `detect_version` honours `tailwind.version`, else sniffs v4 (`@import "tailwindcss"`,
  `@theme`) versus v3 (JS config).
- Static read: v3 `theme` and `theme.extend` object literals; v4 `@theme` custom properties with
  `var()` resolution. Unresolvable references are kept in `unresolved_vars`.
- Runtime: unless `Options::static_mode`, the `crunk-tailwind` runtime resolves the real theme and
  is merged over the static read (`ThemeSource::Runtime`); otherwise `ThemeSource::Static` names why.
- Namespaces use v3 names (`colors`, `spacing`, `borderRadius`, `screens`, `fontFamily`, ...);
  `theme_map()` flattens to `namespace.key` -> resolved value. `namespace_keys` strips the token
  prefix when deriving steps; `<alpha-value>` colors set `alpha_companion`.
- Collisions: an `extend` key matching a Tailwind default is a `Collision` (TW004 default color
  name, TW005 default scale key). Waive with `crunk:waive TW005 reason=...` on the same line or the
  line above; the reason is recorded.
- Limits: the static JS reader ignores spreads and computed keys.
- Goldens: `tests/fixtures/tailwind/tailwind_v4.theme.json` is regenerated by
  `tests/fixtures/dump_tailwind.py` against the Python crunk.
