---
id: INV-026
statement: SYS101 (a may capability declared but never observed) is
  skipped for a node whose entire code= glob set resolves to
  graph-excluded paths, but still fires normally for any node with at
  least one non-excluded observable file
criticality: medium
evidence:
  - tests/unit/strata/test_selfconform.py::TestStaleDesign::test_stale_design_skips_node_fully_within_graph_exclude
  - tests/unit/strata/test_selfconform.py::TestStaleDesign::test_stale_design_still_fires_when_node_has_non_excluded_file
  - tests/unit/strata/test_selfconform.py::TestStaleDesign::test_stale_design_fires
---

`_fully_excluded_node_ids` computes which nodes' entire `code=` glob set
resolves to `[graph].exclude`d paths -- such a node has provably zero
files capability observation could ever see, so "declared but never
observed" is a category error, not real design drift. `_stale_design_
violations` (SYS101) skips exactly those nodes and no others: a node with
even one non-excluded observable file is unaffected, and SYS101 still
fires normally for a genuinely unobserved declared capability there.

`test_stale_design_skips_node_fully_within_graph_exclude` proves the skip
fires for a fully-excluded node; `test_stale_design_still_fires_when_
node_has_non_excluded_file` proves a partially-excluded node is NOT
skipped; `test_stale_design_fires` proves the baseline positive case
(ordinary declared-but-unobserved capability) still fires.
