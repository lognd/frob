id: INV-052
statement: "record_rapid_debt only ever appends a new JSON line to
  .frob/rapid-debt.jsonl -- an existing entry is never rewritten or
  deleted by it; VerifyStatus.rapid_debt_live is always a tuple, empty
  rather than null, when no post-land-unscoped-sweep-deferred entry is
  currently live"
criticality: medium
evidence:
  - tests/unit/test_rapid_debt.py::TestRecordRapidDebt::test_appends_one_json_line_per_call
  - tests/unit/verify/test_verify_runner.py::TestLiveRapidDebt::test_clean_status_has_no_live_rapid_debt
  - tests/unit/verify/test_verify_runner.py::TestLiveRapidDebt::test_other_skip_reasons_are_not_counted
---

`frob.tickets._evidence.record_rapid_debt` opens `.frob/rapid-debt.jsonl`
with `path.open("a", ...)` and writes exactly one JSON line per call --
there is no other write path to this file, so no call can rewrite or
remove a line a prior call already wrote.
`test_appends_one_json_line_per_call` proves two successive calls leave
both lines intact and in order, not just that the latest call's own line
exists.

`frob.app.verify_runner._live_deferred_sweep_debt` (the reducer behind
`VerifyStatus.rapid_debt_live`) builds its result as a `dict` keyed by
`(commit, ticket_id)` and returns `tuple(live.values())` -- an empty dict
yields `()`, never `None`. `test_clean_status_has_no_live_rapid_debt`
proves a repo with no debt log at all reports `()`;
`test_other_skip_reasons_are_not_counted` proves a debt line whose
`skipped` reason is not `post-land-unscoped-sweep-deferred` is filtered
out rather than leaking into the count -- the field stays an empty tuple
rather than a bare non-`post-land-unscoped-sweep-deferred` entry
surviving into it.
