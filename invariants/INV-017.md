---
id: INV-017
statement: run_mutations always restores the target file's original
  source after every mutant, including on error; a crashed run never
  leaves mutated source behind
criticality: high
evidence:
  - tests/test_mutate.py::test_run_mutations_survivors_when_tests_weak
  - tests/test_mutate.py::test_run_mutations_all_killed_by_strong_test
---

`run_mutations` writes each mutant's source over the target file to run
the test command against it, then restores the ORIGINAL source via a
`try`/`finally` around `_run_mutants` -- `target.write_text(original,
...)` runs whether the mutant run succeeded, failed, or raised, so a
crash mid-mutation cannot leave a real source file permanently mutated on
disk.

`test_run_mutations_survivors_when_tests_weak` runs a full mutation pass
and asserts the file's content on disk equals the original source
afterward; `test_run_mutations_all_killed_by_strong_test` exercises the
same restore path via the opposite (all-killed) outcome, end to end
through a real subprocess pytest invocation rather than a mock.
