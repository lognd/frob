---
id: INV-004
statement: A malformed ticket file hard-fails load_queue rather than being silently skipped
criticality: high
evidence:
  - tests/test_tickets.py::TestQueue::test_malformed_frontmatter_is_err
---

`load_queue` is the single read path every gate (COV002, COV003, SCOPE001,
PRE001) and every `frob ticket` command trusts for "what tickets exist and
what state are they in." If a malformed ticket file were silently dropped
instead of failing the load, a ticket could vanish from the queue without
anyone noticing -- an open ticket a diff is scoped to would stop resolving,
turning a real coverage/scope violation into false-negative silence, which
is worse than a loud parse error.

`test_malformed_frontmatter_is_err` writes a ticket file with no YAML
frontmatter at all and asserts `load_queue` returns
`Err(TicketError.MalformedFrontmatter)` for the whole queue load, not a
per-file skip.
