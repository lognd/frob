`src/frob/app/app.py::_import_runner_module` (T-1337) dispatches through a
closed if/elif chain of literal `import frob.app.<name>_runner as module`
statements, one per `_RUNNER_MODULE_NAMES` entry, so `frob.vet._capability`'s
ordinary import-graph resolver can see every reachable target statically
(the whole point of the T-1337 rewrite away from `importlib.import_module`'s
runtime string computation, which OPAQUE001 cannot see through). The
exclusivity claim both `_import_runner_module` and `__init__.py`'s
`__getattr__`-based re-export shim's docstrings make in prose --
"only the one matching branch executes, so only that one module ... is ever
imported" -- is exactly the closed-domain property this repo wants
mechanically pinned, not just asserted.

`test_imports_only_the_requested_subcommands_module` proves it: it clears
`sys.modules` of every `frob.app.*_runner` entry, resolves a single
subcommand's runner, and asserts that subcommand's own runner module is the
only one present in `sys.modules` afterward -- a sibling runner module
appearing there would mean a branch above did more importing than its own
one line, silently pulling in modules (and their transitive import graphs)
the invoked subcommand never asked for.
