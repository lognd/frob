---
id: INV-016
statement: _BelowLevelFilter only lets records strictly below its
  configured level through; a record at or above that level is always
  dropped
criticality: medium
evidence:
  - tests/unit/test_logging_module.py::test_below_level_filter
---

`_BelowLevelFilter.filter` returns `record.levelno < self._below` -- the
stdout handler this filter attaches to only ever emits records below the
configured threshold (WARNING by default), keeping WARNING+ routed to
stderr instead. There is no other path a record can reach stdout through
in the shared logging setup.

`test_below_level_filter` constructs one record below the threshold and
one at it, asserting the filter passes the first and drops the second --
covering both directions of the "only below, never at-or-above" claim.
