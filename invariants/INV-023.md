---
id: INV-023
statement: Only the resolved test endpoint of a frob:tests edge is ever
  added to a runner's selection; the source endpoint is never selected,
  even when the touched set makes it look selected
criticality: high
evidence:
  - tests/test_testing.py::TestSelect::test_reversed_directive_never_selects_the_source_symbol
  - tests/test_testing.py::TestSelect::test_touched_test_file_self_selects
---

`_edge_test_and_source` determines which side of a `frob:tests` `TESTS`
edge is the test (by whether that endpoint's file is itself a test file,
T-0137) regardless of which side the directive was physically written on.
Only that resolved test endpoint is ever passed into a runner's
selection; the paired source symbol is never added, even when the
touched set makes it look selected (e.g. because the test file itself is
new and both of the edge's endpoint node ids appear "touched").

`test_reversed_directive_never_selects_the_source_symbol` is the T-0137
regression case: a `frob:tests` directive written above the SOURCE
symbol, naming the test as its target, with the test file touched --
asserting the source symbol never leaks into the pytest selection (the
original bug crashed collection by passing a non-test node id to the
runner). `test_touched_test_file_self_selects` proves the ordinary case
still works.
