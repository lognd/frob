statement: File-/directory-level COV003 evidence is not vacuous -- a path
  with zero matching collected node ids always fails, "this file/dir
  passes" only counts when something under it actually collected
criticality: high
evidence:
  - tests/test_gates.py::TestCoverageGate::test_cov003_rejects_empty_directory_level_evidence
  - tests/test_gates.py::TestCoverageGate::test_cov003_passes_for_directory_level_evidence
  - tests/test_gates.py::TestCoverageGate::test_cov003_passes_for_file_level_evidence
---

`_path_level_evidence_collected` resolves a bare-path (no `::`) evidence
id by checking whether at least one COLLECTED node id actually lives
under it (as that exact file, or inside that directory). An empty or
nonexistent path -- zero matching collected node ids -- returns `False`,
the same as any other unresolvable evidence; COV003 would otherwise let a
typo'd or deleted directory silently "pass" evidence review, which is
exactly the incident (root-cause, 2026-07-19 main-red) T-0298 fixed.

`test_cov003_rejects_empty_directory_level_evidence` drives an evidence
path with nothing collected under it and asserts COV003 still fires;
the two matching `_passes_for_*` tests prove the positive case (a real,
populated file/directory) is honored, confirming the check is
non-vacuous in both directions.
