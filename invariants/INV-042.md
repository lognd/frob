criticality: high
evidence:
  - tests/unit/test_design_invariants.py::TestInv007::test_forbidden_import_fires
  - tests/unit/test_design_invariants.py::TestInv007::test_clean_module_no_finding

T-0611's actual incident: a `TypeScriptAdapter` landed inside
`src/frob/arch/_normalized.py` -- the deliberately parser-free shared model
module every language adapter (`_python.py`, `_typescript.py`, `_cpp.py`,
...) exists precisely to keep tree_sitter-free -- and a human reviewer
caught it by reading the diff, not by any check. T-0757 turns this design
invariant into a gate: `frob:invariant INV-042 no_import="tree_sitter"`,
anchored at the top of `_normalized.py`, and `frob.gates._design_invariants.
inv007_violations` (INV007) fails the instant that file's own raw import
specifiers (`frob.lang.extract_imports`) contain `tree_sitter` or any
`tree_sitter.*` submodule. The same class of regression is now a static
finding, not a review catch.
