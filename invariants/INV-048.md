SYS103 (`_coverage_totality_violations`, `src/frob/strata/_selfconform.py`)
is `frob sys audit`'s coverage-totality rule (T-0667,
`docs/modules/strata.md#sys-cov-coverage-totality-sys103-t-0667`): a
`FOREIGN` file (one no strata node's `code=` glob binds) that the
binding-aware scanner observes ANY capability in is a hard failure, not a
silent gap. This is the closed-set / exclusivity claim `docs/modules/
strata.md` makes ("must bind to exactly one strata node") -- without a
standing invariant it can rot silently if SYS103's own enforcement site
regresses.

`test_foreign_file_with_capability_fires_sys103` proves the positive case:
a file with an observed `net` effect and no binding node fires SYS103 even
though SYS100/SYS101 (which only reconcile already-bound files) have
nothing to say about it.
