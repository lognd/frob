---
id: INV-008
statement: frob clean only ever removes allowlisted, non-git-tracked
  artifact matches; a git-tracked candidate is always skipped and
  surfaced, never removed
criticality: high
evidence:
  - tests/test_clean.py::test_scan_skips_tracked_files
  - tests/test_clean.py::test_clean_never_touches_src
  - tests/test_clean.py::test_scan_tier1_matches_expected
---

`frob.clean.scan` matches candidates against a known allowlist of glob
patterns per tier (`tier_patterns` plus `frob.toml`-declared extras), then
partitions matches by `_tracked_paths(root)`: anything git-tracked is
appended to `skipped_tracked` and logged, never to the removal `entries`
list. `clean(..., dry_run=False)` only ever acts on `scan`'s already-
computed `entries` -- there is no separate, broader deletion path that
could remove something `scan` did not already report.

`test_scan_skips_tracked_files` proves a git-tracked file matching a clean
pattern is routed to `skipped_tracked`, not `entries`; `test_clean_never_
touches_src` proves a real `clean()` execution leaves tracked source
files in place; `test_scan_tier1_matches_expected` proves the allowlist
is closed (only the declared tier patterns match), not an open-ended
"everything untracked" scan.
