  derived from real HostManifest intersection (group/sudoers/writable

  - tests/unit/strata/test_host_isolation.py::TestVerticalIsolation::test_sudoers_does_not_fire_when_undeclared
  - tests/unit/strata/test_host_isolation.py::TestLateralIsolation::test_disjoint_groups_do_not_fire_shared_group

`evaluate_lateral_isolation`/`evaluate_vertical_isolation` derive every
HOST001/HOST002 sub-target finding (shared-group, sudoers,
shared-writable-path, setuid, ...) from actual `HostManifest`
intersection over declared node attributes -- a user with a genuine grant
fires, a user with none does not. T-0272 replaced the earlier
"unconditionally fires until waived" honest-gap placeholder for the
`shared-group`/`sudoers` sub-targets with this real derivation.

`test_sudoers_always_fires_as_honest_gap` (name kept for T-0256 evidence
continuity, behavior updated) proves a user with a real sudoers grant
fires; `test_sudoers_does_not_fire_when_undeclared` proves a user with no
`sudoers` clause produces no finding -- together showing the check is a
real intersection, not an always-fire placeholder.
`test_disjoint_groups_do_not_fire_shared_group` proves the same for the
`shared-group` sub-target: two users in genuinely disjoint groups do not
fire.
