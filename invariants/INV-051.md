`find_policy_weakenings` (`_policy.py`, T-1482) is the enforcing code
docs/strata/policy.md's refinement-monotonicity paragraph previously
disclosed as missing (`<!-- frob:waive INV003/INV004 -->`, now removed).
For every pair of `CompiledPolicy` whose `node_ids` sets are related by
strict containment (a `component` policy nested inside a broader
`trust`/`label` policy, or one `trust`/`label` threshold nested inside a
laxer one), it diffs the two policies' rules per target atom and flags
any rule the NARROWER (child) policy re-declares less restrictively than
the containing (parent) policy already required.

Deliberately silent when the child never re-declares a given target at
all: TIER-2 conformance enforcement applies the UNION of every policy
whose scope covers a node (docs/strata/policy.md#compilation), so an
un-touched target is simply inherited from the parent, not weakened --
this invariant is about explicit re-declaration only, not implicit
absence.

`forbid call`/`forbid import` are deliberately excluded from the diff
entirely, not just silent-on-absence: they are purely additive
prohibitions under union enforcement, so a child re-declaring `forbid
call` with a DIFFERENT ident set can never make the parent's own
prohibitions stop applying -- there is no way for this form to be
weakened by any child re-declaration, so flagging one would be a false
positive (an earlier implementation attempt compared aggregate ident
sets per rule kind and did exactly this: any child forbid_call rule not
literally re-listing every parent ident read as "dropping" it, caught by
`test_no_finding_when_child_never_overlaps_parent_scope`/
`test_forbid_call_never_flagged_even_when_child_narrows`).

`_confine_weakenings` covers `confine use` (home must stay the same path
or narrow to a sub-path); `_at_call_require_weakenings` covers `at call
... require arg` (arg-set containment per ident); `_mediate_weakenings`
covers `mediate` (no proof-strength ordering exists between two distinct
mediators at TIER-1, so ANY mediator swap for an already-mediated ident
is flagged, fail-closed rather than silently assumed equivalent).

Not yet wired into a TIER-2 gate (`frob check`) -- this ticket built the
diff pass itself, scoped to `docs/strata/policy.md` /
`src/frob/strata/_policy.py` / `tests/unit/strata/test_policy.py`; gate
wiring is a separate, disclosed follow-up.
