`docs/strata/reliability.md`'s REL2xx section makes two exclusivity/
normative claims `check_reliability_timeouts` (`src/frob/strata/
_reliability.py`) actually enforces: (1) REL200 -- every `Flow` in this
grammar already crosses a real process/service boundary by construction
(no in-process/self-flow construct exists), so deny-by-default TIMEOUT
applies to the WHOLE flow set unless a modeler explicitly exempts one;
(2) REL201 -- a flow that DOES declare `timeout` still needs its
originating node bound to real code containing a `timeout=`-shaped
token, per the T-0331 provability constraint (declaration alone never
discharges the obligation). Both are checked, not merely asserted: the
first evidence test proves a flow with no `timeout` attr and no
exemption fires REL200; the other two prove REL201's declared-but-
unproven vs declared-and-proven split.
