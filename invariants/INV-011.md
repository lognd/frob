statement: A region hit at or above the configured threshold is always a
  DUP001/DUP002 violation unless explicitly waived; dup_gate is silent
  by default and never fires while [dup].enforce is off
criticality: medium
evidence:
  - tests/test_gates.py::TestOptInGates::test_dup_gate_off_by_default
  - tests/test_gates.py::TestOptInGates::test_dup_gate_fires_on_planted_clone_when_enabled
  - tests/test_gates.py::TestOptInGates::test_dup_gate_planted_clone_waived_passes
---

`dup_gate` is opt-in (`[dup].enforce` defaults to `false` in `frob.toml`)
and a no-op until a repo turns it on -- it does not silently start
flagging clones a project never asked to be checked for. Once enabled, a
clone at or above the configured similarity threshold is reported as a
`DUP001`/`DUP002` `Violation` naming both regions and the extraction
target; a `frob:waive` directive at the site suppresses it the same way
every other gate rule's waiver does.

`test_dup_gate_off_by_default` proves the gate is silent with no config
key set; `test_dup_gate_fires_on_planted_clone_when_enabled` proves a
planted clone is reported once `[dup].enforce` is true;
`test_dup_gate_planted_clone_waived_passes` proves a reasoned
`frob:waive` on that same clone suppresses the finding.
