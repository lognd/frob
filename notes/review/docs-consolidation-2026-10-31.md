## 1. Scope and method

Every tracked `*.md` was enumerated with `git ls-files` (1944 files). The hand-maintained set
(165 files: root docs, crate READMEs, docs/ outside generated output, notes/, packaging/) is
inventoried one row each in section 2. Mass-produced or generated groups are counted, not
row-listed, because they are not editorial decisions:

| Group | Files | Treatment |
|---|---|---|
| generated rule pages (docs/reference/rules/**) | 268 | generated by gob-dev rules.rs; paths stay unless generator changes |
| generated crunk rule pages (docs/crunk/rules/**) | 1 | generated; stays |
| rule source docs (crates/*/src/rules/*.md) | 227 | source of the generated pages; untouched |
| mdtest fixtures (crates/*/tests/mdtest*/**) | 143 | test inputs; untouched |
| test corpora (crates/*/tests/**) | 40 | test inputs; untouched |
| ticket templates (crates/frob-ledger/templates/**) | 10 | embedded templates; untouched |
| tickets/ ledger entries | 0 | no tracked md |
| changelog.d fragments | 1090 | compiled and removed at release; untouched |

Inventory columns: size is bytes in kB (1000); status is the `Status:` header (docs/ only
enforces DOC003; notes/ files keep status in notes/README.md, shown as "-" when absent); last
change is the date of the last commit touching the file; in = inbound markdown links from other
md files; edges = real `frob:doc`/`frob:describes` edges; cites = md files citing the path in prose
(`x.md section N`, DOC006 scope); code = non-md files (Rust, toml, workflows) naming the full path.
Counts come from a script over `git grep`; basename-only citations are noisy and excluded.
